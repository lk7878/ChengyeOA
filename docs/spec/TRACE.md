## 维护说明

- 本矩阵为项目全局追溯入口，每次 SPEC 立项/验收、每次新模块进入实现时，更新对应行的「已落地SPEC」与「现状」两列。
- 与各文档 frontmatter `implements` 字段配合：`grep "implements: SPEC-" docs/spec/**/*.md` 可快速统计哪些需求已由哪个 SPEC 落地。
- 详情下沉到各 spec 文档；本表保持模块级粗粒度，不新增功能点级行。
