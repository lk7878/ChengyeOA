## 3. 业务规则

1. 驾驶舱可按日、周、月展示一致口径的经营、财务、交付、质控和品牌指标。（源自 §3.3.8）
2. 驾驶舱支持日、周、月三个统计周期。核心指标默认支持按总所、分所、专业团队、渠道、人员维度筛选。经营统计允许最终一致，可通过定时统计或事件表刷新。（源自 §8.12）
3. 驾驶舱和报表是统计消费端，不作为业务主数据修改入口。（源自 §3.3.8）

## 4. 数据对象

驾驶舱为对既有模型的聚合查询，无独立 driving 数据模型；聚合口径见 FTN-001。

## 5. 状态机

无（见 FTN-002）。

## 6. 验收要求

- 驾驶舱可按日、周、月查看经营、团队、财务、交付和品牌指标。（源自 §14.2 步骤 7）
- 驾驶舱日、周、月展示一致口径的经营、财务、交付、质控和品牌指标。（源自 §3.3.8、§14）
