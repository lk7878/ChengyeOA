# 个人文件删除与恢复

本轮增加文件单选 / 多选批量删除、确认对话框与所有者回收站恢复。仅文件管理者可删除（不包括只有全局审计权限的超级管理员）；文件夹暂不提供批量删除。

服务端在个人文件树事务锁内一次校验所有文件管理权限、类型和版本，全部通过才软删除并记录审计。被删除文件不出现在普通列表，下载、材料读取、更新、分享和投稿权限检查均拒绝访问。内容及历史版本保留，所有者可恢复至原目录；恢复时检查父目录权限并沿用原分享设置。已经复制出的知识投稿快照、正式案件归档不受删除影响。引用被删材料的运行中 AI 任务可能因授权失效而中断，确认对话框已说明。
