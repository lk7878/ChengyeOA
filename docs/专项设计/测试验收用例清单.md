# 测试验收用例清单

## 1. 测试层级

| 层级 | 目标 |
|---|---|
| 单元测试 | 状态转换、权限判定、字典校验、金额计算、事件幂等 |
| 集成测试 | PostgreSQL、Prisma 事务、文件存储、AI 适配器、事件投递 |
| API 测试 | 参数、认证、权限、数据范围、错误码、幂等、并发 |
| 端到端测试 | 浏览器完成核心经营闭环和管理员配置闭环 |
| 非功能测试 | 性能、备份恢复、安全、审计、故障恢复 |

## 2. 测试角色与数据

准备系统超级管理员、系统管理员、管委会、分所负责人、客服、邀约、谈案律师、团队负责人、承办律师、财务、人事各一组账号；至少准备两个分所、三个专业团队和 L1-L4 数据样本。

## 4. 专业团队用例

- 医疗：病历清单、完整性核验、分析报告、专家意见、鉴定/诉讼节点。
- 执行：财产线索、调查成本、执行概率、措施和回款进展。
- 刑事：12 节点均可创建任务、上传材料、使用模板和记录专家指导；资料默认不阻塞流转。
- 系统管理员调整节点资料要求后，仅对适用范围和目标版本生效。

## 5. 权限与安全

| 用例 | 预期 |
|---|---|
| 分所 A 用户访问分所 B 数据 | 拒绝或不返回记录 |
| 承办律师访问无关案件 | 拒绝 |
| 无字段权限查看电话/金额 | 返回脱敏值或不返回 |
| 无导出权限导出 L3/L4 | 拒绝并记录尝试 |
| 系统管理员给本人提权 | 拒绝 |
| 系统管理员审核本人操作 | 拒绝 |
| 超级管理员查看 L4 | 仍校验字段权限并记录目的 |
| 临时授权到期 | 自动回收且会话权限刷新 |

## 6. 配置与管理员治理

## 7. 状态机、事务与幂等

- 每个状态机验证合法转换、非法转换、重复提交和并发版本冲突。
- 合同生效失败时，应收、任务、案件和 EventLog 全部回滚。
- 重复收款确认不得重复核销。
- 重复事件和回调不得重复创建任务、通知、应收或案件。
- 客户合并必须保持所有关联完整，并能追踪原客户 ID。

## 8. 事件、审批与自动化

- EventLog 与业务写入同事务。
- EventDelivery 支持成功、重试、失败和人工处理。
- 有序对象事件按顺序消费。
- 审批支持同意、拒绝、撤回、转交、超时和重复点击。
- 自动化规则在测试模式不产生写入，发布后按 eventId 幂等执行。

## 9. 文件与 AI

- local/object 两种驱动上传、下载、归档和 Hash 验证。
- L3/L4 下载鉴权、审计和短时链接。
- 实时转写、上传后转写、失败重试、供应商切换。
- AI 结果不能在人工确认前修改正式业务状态。
- API Key 不出现在数据库、日志、接口响应和前端包中。

## 10. 非功能验收

| 项目 | 目标 |
|---|---|
| 常用列表 | 正常数据量下 2 秒内返回 |
| 并发 | 100 名内部用户在线设计余量 |
| 大文件 | 上传不阻塞普通 API 请求 |
| 可恢复性 | 数据库 RPO ≤ 1 小时，RTO ≤ 4 小时演练 |
| 可观测性 | 请求、事件、AI、定时任务失败可按 traceId 追踪 |
| 备份 | 数据库与文件备份可恢复且关联一致 |

## 11. 发布门禁

以下条件全部满足方可进入生产发布：

1. 核心端到端用例全部通过。
2. P0/P1 缺陷为零，无未处理的数据泄露、金额错误、越权或事务一致性问题。
3. PostgreSQL 迁移验证、备份恢复和回滚演练通过。
4. 权限矩阵、状态机、事件清单和 API 文档与实现一致。
5. 管理员高风险审核、配置回滚、审计查询通过验收。
6. AI 与文件敏感数据安全检查通过。
