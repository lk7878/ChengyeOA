# 页面与接口清单

## 1. 页面通用要求

- 所有列表支持分页、筛选、排序、关键词、保存视图和数据范围过滤。
- 详情页统一展示基础信息、关联对象、状态时间线、附件、审批、事件和审计摘要。
- 按钮由前端权限控制显示，服务端再次校验。
- 所有页面具备加载、空数据、无权限、失败、并发冲突和重试状态。
- L3/L4 字段按权限脱敏，下载和导出显示用途确认。

## 4. 详情聚合接口

客户全景、合同详情和案件详情使用应用服务聚合，不允许前端并发读取无权限的底层资源。聚合接口必须按字段权限裁剪响应，并返回可执行动作列表 `allowedActions`。

## 5. 导入导出

- 导入流程：上传 → 解析预览 → 字段映射 → 校验 → 确认写入 → 结果报告。
- 导出流程：选择范围和字段 → 权限/数据级别校验 → 审批（如需）→ 异步生成 → 短时下载。
- L3/L4 导出记录用途、审批和水印信息。

## 6. 页面验收

每个页面至少验证：默认视图、筛选分页、详情关联、允许/禁止动作、空状态、失败重试、并发冲突、数据脱敏、移动端基本可用性。
