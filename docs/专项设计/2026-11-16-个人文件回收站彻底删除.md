# 个人文件回收站彻底删除

回收站每行新增“彻底删除”，显示文件名和不可恢复提示，经确认后执行。取消不会发送删除请求。只有文件所有者可以彻底删除已进入回收站的文件；共享管理者和全局审计管理员不能据此删除他人的文件。

## 删除范围与一致性

- 删除个人文件记录、全部内容版本、发布授权、对应上传会话，以及当前/历史版本的磁盘文件和上传分片。
- 单独保存的正式案件归档、知识库副本保持独立；原有审计和来源链引用不伪造、不改写。
- 先以数据库事务保存清理凭据，再移除磁盘文件。磁盘清理失败时，回收站显示“重试彻底删除”，禁止恢复，服务重启后仍可继续清理。
- 清理完成后保留最小完成凭据和操作审计，重复请求不会再次执行删除。
- 文件树锁、版本校验和上传锁共同防止恢复/更新/删除竞争；上传开始时在文件树锁内重新验证文件，避免为已删除文件创建新的上传会话。
- 若磁盘对象还被其他个人文件引用，拒绝清理，避免误删。
