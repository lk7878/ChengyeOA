# 三大专业团队 SOP 系统字段清单

## 1. 通用模型

| 对象 | 核心字段 |
|---|---|
| SopTemplate | code、name、professionalCategory、caseType、version、status、effectiveScope |
| SopNodeTemplate | nodeCode、nodeName、sequence、description、defaultOwnerRole、reminderRule |
| MatterNodeRequirement | nodeCode、materialType、required、templateId、instruction、status |
| MatterNode | matterId、nodeCode、status、ownerId、startedAt、completedAt、progressNote |
| MatterTask | nodeId、taskType、title、assigneeId、dueAt、status、reviewerId |
| ExpertGuidance | matterId、nodeId、expertId、guidanceType、content、attachmentIds、createdAt |

节点文书、专家指导和资料上传默认不阻塞下一节点。系统管理员可按专业团队、案件类型和节点配置资料要求；本需求不设置统一节点完成标准。

## 2. 通用案件字段

- 客户、案件编号、合同、分所、专业团队、主办律师、协办律师、助理、专家指导人。
- 案件类型、案由、对方当事人、标的额、受理机构、当前阶段、风险等级。
- 客户目标、律师目标、目标对齐结论、风险告知、材料完整度、分析结论。
- 节点状态、负责人、计划时间、实际时间、材料、模板、专家意见、审核记录。

## 3. 医疗纠纷团队

### 3.1 SOP 节点

客户到访 → 病历收集 → 材料完整性核验 → 病历分析报告 → 目标对齐 → 正式签约 → 深度分析 → 鉴定/诉讼/调解 → 结案复盘。

### 3.2 专属字段

| 分类 | 字段 |
|---|---|
| 医疗主体 | 医疗机构、科室、医生、就诊时间、住院号、诊疗阶段 |
| 材料 | 门诊病历、住院病历、医嘱、检查报告、影像、费用清单、死亡记录、知情同意书 |
| 争议 | 诊疗行为、损害结果、因果关系、过错点、告知义务、举证难点 |
| 专家意见 | 专家、专业方向、意见摘要、风险、建议补充材料 |
| 分析报告 | 报告版本、结论、责任判断、鉴定建议、诉讼策略、审核状态 |

病历收集和报告时限使用可配置提醒，不固化工作日 SLA。

## 4. 执行团队

### 4.1 SOP 节点

证据收集委托 → 全面网查 → 财产线索整理 → 案件分析报告 → 执行可能性判断 → 目标对齐 → 正式签约 → 执行方案 → 衍生诉讼/措施 → 结案复盘。

### 4.2 专属字段

| 分类 | 字段 |
|---|---|
| 基础信息 | 执行依据、执行法院、执行案号、申请执行人、被执行人、执行标的 |
| 财产线索 | 银行账户、不动产、车辆、股权、应收账款、知识产权、网络资产 |
| 调查记录 | 查询渠道、查询时间、结果、证据文件、有效期、调查成本 |
| 分析判断 | 可执行概率、优先财产、查控建议、衍生诉讼、风险和成本预估 |
| 进展 | 执行措施、法院沟通、回款金额、剩余标的、下次动作 |

客户进展告知按合同约定或负责人配置，不作为所有案件强制周报。

## 5. 刑事辩护团队

### 5.1 十二个节点

| 序号 | 节点编码 | 节点名称 | 建议模板 |
|---:|---|---|---|
| 1 | CR_FIRST_RECEPTION | 首次接待 | 首次接待记录 |

| 6 | CR_BAIL_APPLICATION | 取保候审申请 | 申请书模板 |
| 7 | CR_AUTHORITY_COMMUNICATION | 办案机关沟通提纲 | 沟通提纲 |
| 8 | CR_STATEMENT | 陈述意见 | 陈述意见模板 |
| 9 | CR_FILE_REVIEW | 阅卷笔录 | 阅卷笔录 |

| 12 | CR_DEFENSE_STATEMENT | 辩护词 | 辩护词模板 |

### 5.2 专属字段

- 涉嫌罪名、办案机关、程序阶段、强制措施、羁押地点、会见时间。
- 指控事实、证据体系、争议焦点、非法证据、量刑情节、辩护方向。
- 会见重点、当事人陈述、阅卷摘要、证据矛盾、质证意见、庭审策略。
- 专家指导人、指导意见、文书版本、审核人、审核结论、模拟法庭记录。

## 6. 配置与版本

1. SOP 模板按专业团队、案件类型、版本和适用组织发布。
2. 已建案件绑定发布时的 SOP 版本，不随新版本自动改变。
3. 系统管理员可调整节点资料要求、模板和提示；高风险删除或结构调整需超级管理员审核。
4. 模板停用不删除历史文件和案件引用。
