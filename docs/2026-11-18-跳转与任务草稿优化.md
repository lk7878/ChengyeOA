# 跳转与任务草稿优化

本轮仅修改独立工作目录的智慧办案仓库，没有部署、推送或修改 OA 源码；沿用 OA 已有身份交换流程。修改前恢复点：`8c80c2b`。

## 行为

- 工作台栏目写入 `view` 查询参数，支持刷新、前进和后退；旧 `caseId` 入口继续进入通用任务。未知栏目回到概览，非超级管理员不能进入授权与 AI 管理。
- 新建任务草稿使用当前标签页的 `sessionStorage`，以 OA 映射账号 ID 和任务类型分别存储。保存任务名称、关联案件、文件及具体版本、知识库选择、文件范围和目录。最多保留 7 天，关闭标签页或主动退出登录时不再保留对应草稿。不保存凭证、文件内容或会话令牌。
- “尚未初始化知识库选择”和“主动全部取消”分别记录；后者不再自动勾回法律法规库。创建失败保留草稿，创建成功移除对应草稿。
- 恢复草稿及提交创建前重新取得当前案件、知识库授权和所选文件版本；撤销的授权、失效的具体版本会移除并提示核对。网络失败保留草稿、阻止提交，提供重新校验按钮。没有擅自替换为文件的新版本。
- 文件版本读取有等待反馈，期间禁止创建；取消选择后迟到的版本响应不能重新勾选文件。其他目录的已选文件也展示并可取消。
- 知识库分类、文件名筛选、检索文本、列表页码保留在 URL。知识库与投稿记录分别加载，投稿失败不再遮挡知识库。区分加载中、无授权、请求失败及没有匹配内容；切换库或关键词后，旧检索响应不再覆盖当前结果。
- 顶部和概览快捷入口改为 AI 任务，不再展示外部打开标识；已有任务的“打开 AI 会话”仍在新标签页打开。
- AI 会话和原生知识管理的 HTML 入口按 HTTP 状态展示登录失效、权限不足、停止/中断、不可访问或连接故障页面，并提供返回工作台、重新通过 OA 进入或重试入口。JSON API 和实时连接的权限规则保持生效；不自动启动/重启任务。
- OA 登录返回目标只接受本站 `/wb/` 下允许的导航参数，使用短时 HttpOnly Cookie 传递，回调/退出时清除。旧 PKCE 和 `caseId` 流程继续有效。上游身份服务故障显示暂不可用，不再一律误报为登录失效。

## 验证

- `npm run build --prefix work_ui`：TypeScript 和 Vite 构建通过。原有 `oa-theme.js` 非 module 脚本提示保留，该脚本按原方式独立加载。
- `node --test case-service/test/*.test.js`：45 项通过，包含任务所有权、授权撤销、HTTP/SSE/WebSocket 管控及新增入口落地页/返回地址验证。
- `node work_ui/test/navigation-drafts.mjs`：20 个浏览器场景通过，使用本地构建和模拟 API。覆盖草稿切换/刷新、前进后退、账号与任务类型隔离、空知识库选择、指定文件版本、创建成功/失败、授权撤销、版本失效、快速取消、显式案件入口、登录失效、退出清理、知识库加载/错误/无授权、筛选分页恢复与迟到响应。
- 本机已有 Playwright 时可设置 `PLAYWRIGHT_MODULE=/absolute/path/to/@playwright/test/index.mjs`；可选 `UI_SNAPSHOT_DIR` 保存本地界面截图。测试自行启动并关闭临时静态服务和浏览器，不请求线上 API。
- 本地页面截图检查通过；没有创建生产账号、文件、任务，也没有重启线上任务。
