# SPEC-EMP-UI-20260911：员工类型中文与完整组织路径

状态：已实现并验证。先规格后实现。关联 MOD-001 员工与任职管理。

## 行为与验收

1. 员工列表、基础档案和新增/编辑表单采用统一人员类型中文映射。覆盖现有表单类型及历史资深/初级律师类型，提交接口仍使用原编码；未知类型保留原值，不能误标为其他类型。
2. 主组织以员工当前有效主职的 organizationId 为终点，显示从总所到该组织的完整名称路径，以 `/` 分隔，例如“重庆承业律师事务所/律师部/民商事组”。不能遍历到与员工无关的更深后代，也不能用兼任覆盖主职。
3. 任职详情的组织、组织筛选、新增员工和调动/兼任组织选项同步使用路径，便于区分同名部门。组织搜索按显示名称/路径匹配；接口提交和筛选仍传组织 ID。
4. 只使用已有权限允许返回的组织树构造路径，不扩大组织读取权限。受限树从可见祖先起显示；节点不可见或目录加载失败时保留已有 ID 回退，无主职显示 `-`，不影响人员列表加载。
5. 完整路径允许换行并提供悬停全文，主组织默认列宽调整为 300 像素，继续支持上一规格的手动列宽和浏览器记忆。
6. 本次只修改显示，不变更员工归属、任职关系和数据库。验证多层树、同名部门、主职终点、受限目录、列表与详情中文类型、中文选项提交原编码；执行相关前端回归、类型检查、变更 lint 和构建。

## 实施位置

共用人员类型映射、组织路径工具、EmployeePage、EmployeeForm、EmployeeDetailDrawer、AssignmentDialog。测试与实施结果记录在对应 plan 中。
