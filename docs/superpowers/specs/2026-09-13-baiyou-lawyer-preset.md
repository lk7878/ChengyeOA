# 百佑办案助手品牌与 lawyer preset

状态：品牌和独立 preset 已验证；本地快照同步待确认。属于 V1.3.0 桌面开发阶段，不改变 OA 当前正式版本。

2026-09-14 部署补充见[云端服务与统一 Windows 客户端部署规格](2026-09-14-production-deployment.md)。唯一 lawyer、旧会话承接与本地快照待决边界不变；安装包、更新及真实云环境另行验收。

## 规格与边界

1. 本地 Harness 名称统一为“百佑办案助手”，会话空白页标题为“让法律服务更智能”，不显示原“预览版”徽标。使用用户提供的百佑智鉴 JPEG 原图替换侧边栏及会话欢迎区鲸鱼标识；保留原生工作区、会话、设置和操作流程。
2. 在 `integrations/intelligence` 内复制原生 standard 组合，构建唯一可用的 `lawyer`（中文名“律师办案助手”）preset，保留文件、Shell、搜索、计划、子代理及工作流等原生能力和授权边界。新增法律任务说明与云端 Wiki 查询指引，不削减其原有工具能力。
3. 正式 Product Profile 仅通过扩展根目录发现 lawyer，新建会话固定默认使用 lawyer，旧默认偏好不再生效。现有只读 `cloud_wiki` 插件继续经 OA 身份桥接查询；不向 Harness 下发 OA 凭据，不自动上传本地办案材料。
4. 品牌和 preset 源码集中维护在集成目录。原 C33 及导入快照源码只读；优先原生 slots、插件客户端入口、preset roots。欢迎语无现成插槽且原生 locale 禁止同名覆盖，允许仅在构建原生客户端时对对应源模块施加有精确匹配检查的品牌转换；转换源码保存在集成目录，生成物不入 Git，不修改原生业务逻辑。

## 2026-09-13 追加确认：只保留 lawyer

桌面部署只发现和展示 `lawyer`，关闭上游预置目录与用户自建目录的发现，不再提供其他模式和复制创建入口，默认值固定为 lawyer。lawyer 内部仍保留复制自 standard 的完整工具组合。

源码隔离边界不变：不删除原 C33 或导入快照中的上游文件，也不清除个人会话和工作区。对历史内置 preset 标识（standard、ptc、minimal、cordis）提供恢复兼容：继续办理时统一由 lawyer 组合承接，历史记录中的原标识不篡改；未知标识仍明确报错，不静默加载任意代码。测试须覆盖唯一可选模式、旧默认值失效和内置旧会话重启恢复。

## Wiki 本地同步方案（待确认后实施）

推荐采用云端管理员发布的只读知识快照，通过独立插件访问，不直接复制正在使用的 SQLite。快照包含获授权阅读的文档文本、已发布编译内容、版本、来源索引与内容摘要；不分发管理员凭据、维护记录、内部 OCR 中间数据和未发布内容。云端继续为权威知识库，本地副本不能反向修改或同步个人工作区。

按 OA 服务地址和账号隔离；每次更新下载至临时版本，验证完整性后原子切换，失败保留上一完整版本，删除和撤回内容通过新版清单处理。资料是证据而非可执行插件代码，不能把远端内容作为 Cordis 配置或 Shell 执行。lawyer 通过本地只读查询工具访问快照，保留出处、版本、行号和更新时间。

尚待用户选择：联网重新校验权限后才能使用本地快照，或允许离线使用且接受撤权无法立即作用于已下载副本。该选择影响访问控制和离线行为，确认前不启用后台下载，也不把当前在线查询宣称为已实现本地同步。
