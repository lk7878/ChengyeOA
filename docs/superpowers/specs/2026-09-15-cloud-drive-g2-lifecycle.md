# 云盘 G2-A：移动、权限预览与回收站

日期：2026-09-15。承接 [云盘规格](2026-09-15-feishu-cloud-drive-resource-center.md) 和 G1 本地提交 5387c520。本批先落盘契约再实现，后续快捷方式、上传、模板、永久删除另行推进。

## 授权与预览

- 所有用户沿用同一云盘界面。生命周期操作要求工作区显式 canManageAccess、源节点有效管理角色；移动还要求目标目录有效管理角色。系统管理员身份和目录 ownerId 不自动授予能力。文件夹整树操作要求所有后代目录节点均可管理，避免隐式操作不可见资源。
- 仅同工作区移动 FOLDER/BASE；禁止移动到自己或后代、跨工作区、已回收目录、超过 8 层的树。单次最多处理 500 个目录节点，超过时提示拆分操作，不执行部分移动。移动保留 Base ID、记录、视图、目录 ownerId 和节点自身 ACL；继承来源改为目标祖先链。
- 预览显示来源/目标可见完整路径、双方逐级独立授权/继承规则与主体、操作者的前后有效权限、受影响文件夹和 Base 数量。明确这是规则差异预览，不是人员人数或完整人员权限模拟；岗位任职、工作区、Base、表和领域约束仍参与最终授权，不能用单个岗位条目代表一个人。
- 预览不修改资源。服务返回绑定操作者、动作、目标、名称及当前目录/工作区/资源 ACL 版本的摘要。提交在工作区排他锁内重新鉴权并核对摘要；目录、成员、资源 ACL 或操作者有效任职变化后拒绝旧预览，要求重新预览。记录内容正常编辑不使目录预览失效。
- 首批摘要覆盖整个工作区的目录结构和 Base/Table 授权元数据：同工作区其他目录整理也可能要求重新预览，这是保守的冲突策略；普通记录写入不参与该摘要。
- 移动可能扩大或缩小其他协作者的继承范围，界面必须显示这一影响并经预览后确认。摘要不替代授权，也不是可转让的访问凭证。

## 回收与恢复

- DriveNode 增加 deletedAt/deletedBy；只标记本次回收的根节点，子树通过祖先链整体不可用。记录/附件/视图不物理删除。原先单独回收的子项在恢复父级后仍保持回收状态。
- 回收站只向授权管理者返回当前可管理的显式回收根；父级也已回收的条目折叠在父级下，不泄露无权节点或数量。普通资源列表、搜索、树、Base/表直链、记录、附件、关联与 SSE 都拒绝自身或祖先已回收的资源，即使工作区 OWNER 也必须先恢复。
- 恢复到原父级，按当前父级及节点自身权限重新计算，不恢复历史人员授权。父级不可用时先恢复父级；不静默恢复到根目录。允许在恢复预览中修改名称以解决同名冲突。
- 活跃同级文件夹名称唯一，回收后可复用，恢复同名返回 409；沿用 Base 名称在工作区内唯一的既有约束，回收 Base 仍保留名称。没有永久删除或定时清理任务。
- 移动、回收、恢复均在同一事务中完成版本、审计和受影响 Base 的协作事件/outbox。幂等重放不重复审计；重新失去授权后不能靠旧幂等键操作。回收和移动后订阅重新鉴权，5 秒内清理失效页面。

## API、UI 与迁移

- POST /api/v1/drive/nodes/:id/lifecycle/preview：action=MOVE/TRASH/RESTORE，MOVE 要求 parentId（null 为根）；RESTORE 可传 name。返回规则预览及 previewToken。
- POST /api/v1/drive/nodes/:id/lifecycle：相同动作参数 + previewToken + Idempotency-Key；仅在摘要和当前权限均有效时修改。
- GET /api/v1/workspaces/:id/drive?scope=trash：权限过滤后的回收站分页、搜索与排序。普通目录 DTO 增加 canMove/canTrash，回收站返回 canRestore。
- 独立生命周期面板：选择目标/恢复名称 → 查看规则与影响 → 确认。修改选择清除旧预览；冲突保留输入并重新预览；网络重试复用相同幂等键。资源菜单开放移动、移入回收站、恢复，侧栏提供回收站。预览期间还须重新校验目标目录及子树，不能仅检查源资源可见；目标被撤权时清除面板。已提交但响应丢失时，保留同一幂等键，不因资源已经改变状态而静默发起第二次操作。
- 增量迁移增加两字段、软删除约束与活跃文件夹部分唯一索引，不重置开发数据。回退访问代码前必须处理软删除边界，不允许旧服务忽略 tombstone 后重新暴露内容。

## 验收与任务顺序

1. 迁移与服务：稳定 ID、整树移动/回收/恢复、名称复用、深度/循环/跨区拒绝；普通用户和无委派管理者拒绝；预览后授权/目录变化冲突，内容写入不冲突。
2. 事务与权限：并发只一个赢家、幂等、事件故障全量回滚、回收子项不随父级复活；SELF/字段/附件/关联、旧入口与 SSE 保持边界。
3. 界面：真实浏览器完成移动预览、确认、回收、搜索消失、其他会话失效、恢复和重新访问；1440/1024/390 布局及失败提示。
4. 回归与负载：原协作和 G1 服务/浏览器回归；沿用 100 会话/20 写入者每 5 秒/900 秒负载及 8 层目录，不降低门槛。迁移到两个隔离测试库和开发库，恢复开发服务，同步状态并提交本地 Git。
