## 3. 对象模型与不可混淆的概念

```text
OA 协作门户
├─ 云盘资源中心
│  ├─ 我的文件夹 / 共享文件夹
│  └─ 文件夹中的资源
│     ├─ 多维表格应用 → 数据表 → 多个视图（共享记录）
│     ├─ 文档 / 电子表格 / 上传文件（分阶段接入）
│     └─ 快捷方式 → 原资源
├─ 待办与业务应用
└─ 管理中心 → 组织、人员、岗位、权限配置
```

1. 保留工作区作为既有成员与授权边界，保留 CollabBase 作为多维表格应用。不得将 Base 或数据表改用为文件夹。
2. 文件夹树组织资源，组织树提供部门、岗位等授权主体；两者不要求一一对应，允许授权范围内跨部门协作。
3. 同一资源具有稳定 ID。个人入口、共享入口和快捷方式引用同一资源，不复制内容以实现共享。
4. “我的文件夹”是资源组织入口；“个人视图”是展示配置的拥有与共享范围；“我的数据”是权限或筛选作用后的记录范围，三者分别定义。
5. 总表和个人视图共享 recordId。视图筛选不替代服务端数据权限，“总表”不代表可查看全组织数据。
6. 新增统一资源元数据、文件夹层级、内容关联和快捷方式能力。资源标题等公共信息必须有唯一权威来源，避免与 Base 双写漂移。
7. 收藏、最近访问等为个人使用状态，不改变资源归属或授予权限。
8. 原审批、财务、案件等领域服务继续掌握业务真值；云盘不复制另一套核心业务数据。云盘不自动读取或同步个人办案目录，沿用既有桌面、本地 Harness 和知识库边界。

## 4. UI 与交互契约

### 4.1 所有角色共享界面框架

员工、负责人、管理员共用同一路由和布局体系，由有效权限决定可见资源与可执行操作。管理中心承载组织和权限配置，但管理员日常协作不使用另一套云盘或表格界面。敏感资源不通过禁用条目暴露名称；对已可见资源的不可用操作，可按场景隐藏或禁用并给出原因。

### 4.2 云盘首页

- 左侧：搜索、可展开的“我的文件夹”“共享文件夹”树、选中态及当前路径定位。
- 主区顶部：新建、上传、添加快捷方式、模板入口；仅开放已实现且有权限的操作，不用无功能按钮充当验收。
- 主区内容：文件夹卡片和资源列表；资源类型图标、标题、修改时间、创建时间、更多菜单。
- 列表工具：排序、显示设置、列表/卡片切换；保留可理解的空态、加载态、失败重试和键盘焦点。
- 资源操作按阶段实现：打开、重命名、移动、共享、快捷方式、回收站。云盘列表不呈现为可编辑业务单元格。

### 4.3 多维表格内部

- 顶部：资源名、所在位置、在线协作者、分享/权限入口；能够返回原文件夹和恢复定位。
- 左侧：应用内数据表目录、搜索及底部“＋”；文件夹树与表目录不得混为同一对象层级。
- 中部：视图标签、字段/视图配置、筛选、分组、排序等工具栏，以及高密度数据网格。
- 侧边：记录详情、评论、历史等按原规格已交付能力展示。
- 云盘和编辑器共用设计变量、组件及反馈规则；不同页面采用适当密度。以布局、常用操作路径和状态完整性验收，不要求复制品牌标识或截图像素。

## 5. 权限契约

G1 的资源身份、迁移回退、权限决策表、API 和验收条件见[云盘 G1 技术契约](2026-09-15-cloud-drive-g1-contract.md)。这是实现前的工程决策，不代表功能已完成；以下原则继续有效。

权限分为资源访问、记录范围、操作与字段三层，复用现有授权引擎，禁止增加仅前端生效的第二套授权规则。

1. 普通用户默认只读取自己填写的记录；本项目既有 SELF 语义以 createdBy 为依据，不能悄然替换为 ownerId。负责人可在获授权的应用/表范围内查看全部记录，并非自动获得全组织权限。
2. 管理员可按现有岗位、部门、成员配置权限；系统管理身份不默认获得所有私有资源的数据读取权。保留并明确现有资源负责人管理规则，不能不经规格修订扩大或收回已有权限。
3. 文件夹权限不得突破工作区及现有应用/表的上级限制。实施前在本规格补齐继承、直接授权、禁止项、负责人例外和移动行为的完整决策表。
4. 分享面板展示资源协作者、数据/字段范围、有效权限来源及受上级限制的原因；不允许通过共享视图绕过行权限。
5. 移动资源前展示继承权限变化；服务端提交时重新校验权限和版本，防止预览后权限变化导致越权。首批限定同工作区移动，跨工作区迁移另行规格化。
6. 快捷方式只引用目标；目标不可访问或被回收后不能通过快捷方式泄露名称、预览或内容。
7. 搜索、列表、数量、预览、最近访问、导出和下载执行一致的权限约束；撤权后历史直链及现有会话均重新校验。

## 7. 分期与验收

### 7.1 阶段边界

- G0：补齐受影响需求、技术契约、权限决策表及追溯；收敛当前协作性能与会话稳定性，记录原规格规定的负载结果。
- G1：云盘最小闭环，包含文件夹、既有/新建 Base 的统一资源入口、资源列表、导航返回、共享及权限验证。权限不是后置补丁。
- G2：完善移动、快捷方式、回收站、模板及上传文件；每项先定义失败、权限和恢复行为再实施。收藏/最近访问按优先级推进。
- G3：独立规格推进更多内容类型、文档实时协作，以及既有规划中的更多视图、公式和自动化。
