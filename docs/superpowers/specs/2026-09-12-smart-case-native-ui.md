# SPEC-AI-UI-20260912：智慧办案复用 Harness 原生界面

状态：已实施，验收结果见同名实施记录。用户要求智慧办案的 UI 与 Harness 原 UI 保持一致，本规格在修改实现前建立。

## 目标与版本

产品升级为 **律师智慧管理系统 V1.2.1**。智慧办案采用导入快照的 Harness 原生布局、会话侧栏、欢迎区、输入区及消息呈现，替换 V1.2.0 定制三栏表单式界面。直接复用原生组件、图标、主题和 CSS，不另做一套近似样式。OA 的主导航与身份权限仍作为外层。

## 交互与边界

用户补充允许浮动窗口，不必受 OA 侧边栏内容区限制；最新指定入口在右上角、紧邻知识库。采用全局单实例浮动工作台：移除 OA 左侧智慧办案菜单，也不另设右下角入口；右上角“智慧办案”负责打开、恢复同一个窗口。支持标题栏拖动、右下角缩放、最小化和最大化，窄屏采用铺满窗口。切换 OA 页面或最小化不卸载原生视图、不关闭办案连接；明确关闭、退出账号或失去模块权限时卸载并清理。标题栏提供可键盘操作的最小化/最大化/关闭按钮，窗口尺寸随视口变化保持可达。直接访问旧 /smart-case 链接也唤起该工作台。

- 模块内使用 Harness 的可折叠会话侧栏、中央对话区、居中欢迎输入区与会话底部输入区；材料区按需打开，可收起，布局支持原生宽度调整。
- 本机材料导入、成果下载、知识库引用、OCR 授权、备份导入导出和持久化授权通过原生布局的工具入口呈现；所有现有能力必须保留。
- 消息支持 Markdown、流式输出和处理状态，保存审批及补充问题保持可操作，错误不得丢失当前输入。中文输入法组合输入不能误提交。
- 聊天中的用户气泡仅呈现原生事件 source.kind=user 的输入；插件注入的运行上下文保留在原生会话记录中，不冒充律师消息显示。审批与问题使用原生接管卡片及原生中文词典。
- 不开放服务器 Shell、任意文件路径、任意插件安装或管理员模型配置。云端 Wiki 仍从 OA 右上入口独立维护，智慧办案仅选择引用。
- 不改变 OPFS 个人资料、会话保存检查点、OA 权限和云端临时进程契约；不新增 HTTP 监听，不安装律师本机服务，不修改原 C33 项目或导入的上游源码。
- 原生组件在独立 React 18 根运行，使用快照主题；OA React 19 仅提供 DOM 和 API。浏览器构建边界按模块分别检查：知识库仍不引入 Harness 办案外壳，智慧办案允许引入其原生会话 UI。

## 验收

1. 构建产物实际包含原生布局、侧栏、欢迎区与输入相关源码，快照指纹不变。
2. 真实浏览器检查欢迎、已打开会话、侧栏收展、材料面板、较窄窗口与滚动，保存截图核对原生视觉。
3. 回归新建/恢复、输入及错误保留、材料导入下载、备份操作、知识库引用；保留原生引擎与 OPFS 检查点/审批回归。
4. 运行涉及的前端构建、类型/样式检查和智能模块测试；更新维护说明及验收记录，最终本地 Git 提交，不推送。
