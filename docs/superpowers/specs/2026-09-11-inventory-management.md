# SPEC-INVENTORY-20260911：物品管理与低值易耗品台账

状态：已实现并验证，已迁移本地开发库并重启服务。来源为用户提供的低值易耗品管理菜单截图；沿用现有组织、员工、授权、审计和可调整列宽组件。先本规格，后实现和验证。

## 1. 目标与界面

侧栏新增“物品管理”，含下列入口。定制物品和办公用品共享物品档案及库存流水，分类展示，避免重复登记。

| 入口 | 内容 |
| --- | --- |
| 物品档案与库存 | 编码、名称、规格、中文分类、定制物品/办公用品、单位、存放位置、库存、预警下限、启停用 |
| 定制物品领用登记 | 定制物品的领用、领用员工、所属组织完整路径、数量、日期、用途 |
| 定制物品领用统计 | 按物品/员工/部门统计指定期间的领用数量 |
| 办公用品领用明细 | 办公用品领用流水，与出库明细关联同一单据 |
| 办公用品领用统计 | 办公用品按物品/员工/部门汇总 |
| 入库明细 | 入库单号、物品、数量、日期、来源/供应商、登记人、备注 |
| 出库明细 | 出库单号、物品、数量、领用人、组织、用途、经办人 |
| 盘点记录 | 物品、账面库存、实盘数量、盈亏、盘点日期、差异原因、盘点人 |
| 领用仪表盘 | 物品种类数、低库存种类数、期间出入库笔数、热门领用物品、按单位展示数量 |

“办公用品库存表”由库存入口切换“办公用品”分类获得；库存也支持定制物品。各列表有中文字段、搜索/分类/日期筛选、分页、列宽拖动、当前筛选结果导出。仪表盘不能把不同计量单位直接相加为一个数量。

## 2. 基础资料和流程

- 物品编码自动生成且唯一；名称、规格、分类、单位和存放位置支持中文。分类文本 1–100 字符；名称 1–100；单位 1–20；位置和规格最多 100。
- 新档案库存为 0，初始数量也必须通过入库登记，不能直接编辑库存。库存数量及入出库数量最多 3 位小数；入出库数量必须大于 0。库存不得为负。
- 管理员/授权保管员登记入库、领用出库和盘点。本期“领用登记”表示实际领用并扣库存，不另建未确认的领用申请，不自动生成费用报销审批。
- 出库须选择在职员工；自动记录其当前主组织完整路径。员工姓名、组织路径、物品名称/规格/单位同时保存历史快照，后续人员调动或物品改名不影响原单据。
- 统计按稳定的物品、员工或组织 ID 汇总，改名不拆分汇总行；统计展示当前名称，原单据继续展示登记时的名称/组织快照。
- 实际领用记录同时出现在对应分类领用明细、出库明细和统计中，均来自同一流水，不重复扣减。
- 已有流水的物品保留档案，可停用；停用后禁止新出入库，库存和历史仍可查。单位/物品类型在已有流水后不可更换，避免混淆历史统计；中文名称等资料可编辑，版本校验防覆盖。
- 单据确定后不提供直接删除或修改库存数量；盘点发现差异时登记盘点及差异原因，产生对应调整流水。

## 3. 库存与盘点一致性

- 所有库存变更在同一事务内锁物品行、校验版本/库存、写流水和安全审计；余额与流水一同提交。
- 出入库及盘点使用用户范围内的幂等键。重复点击/网络重试不重复增加或扣减；同一键内容不一致拒绝。
- 盘点提交包括读取时的物品版本和实盘数，提交时库存已变化则要求刷新重盘，不覆盖中途的出入库。差异非 0 必须填写原因；差异为 0 仍保存盘点记录。
- 数量采用数据库 Decimal 运算；提交超限、非法小数、负数、库存不足、已停用、版本冲突均有中文提示，当前输入保留。

## 4. 权限与数据

- 新权限：menu.inventory、inventory.read、inventory.manage（物品资料）、inventory.inbound、inventory.outbound、inventory.stocktake、inventory.export。
- 超级管理员依现有权限机制拥有全部目录权限；其他人员需显式分配，不隐式扩展其合同、员工敏感字段或财务权限。
- 物品管理为保管职能台账，读取仅 inventory.read 门控；操作人员可使用专用领用人选择接口读取在职员工 ID、姓名、工号和主组织路径，不输出手机号、证件、工资等敏感信息。
- 导出单独校验 inventory.export；导出保留筛选条件和中文列头，文本单元格不得触发 Excel 公式，最多 10,000 行，超过时明确要求缩小范围。
- 新表 InventoryItem、InventoryMovement、InventoryStocktake；引用员工/组织的稳定 ID，并保留快照；不删除既有业务数据。

## 5. 验收

1. 超级管理员能看到九类入口；未授权用户无法访问数据和写入接口。
2. 新建中文物品→入库 10→领用 3→库存 7；出库和分类领用列表只显示同一条出库，汇总为 3。
3. 并发领用不能超发；重试同单不重复扣减；失败保持原库存。
4. 停用物品不能新出入库；历史能查；员工离职后不可作为新领用人，旧领用记录仍在。
5. 盘点 7→实盘 6，要求差异原因，库存变为 6且保留 -1 调整记录；旧版本提交被拒绝；实盘相同仍保留盘点证据。
6. 日期/类别/关键词筛选和中文导出与页面数据一致；统计使用明确日期边界，数量按物品及单位展示。
7. 独立测试库验证事务、权限和幂等；前端类型/lint/构建及浏览器入库领用盘点检查。通过后备份再迁移本地库、重启并检查健康状态。
