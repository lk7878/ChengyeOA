# 云盘 G2-B：快捷方式与最近访问

日期：2026-09-15。承接 G2-A 本地提交 a0301238 和[云盘总规格](2026-09-15-feishu-cloud-drive-resource-center.md)。本契约先于实现；文件上传、模板、永久删除及文档协作仍另行分期。

## 对象、权限与生命周期

- 快捷方式是独立的 DriveShortcut，targetId 只引用同工作区原始 DriveNode（FOLDER/BASE），不复制 Base/表/视图/记录，不存储目标名称和 ACL，不允许指向快捷方式或作为文件夹容器。文件夹快捷方式是导航链接，不进入目录树递归。
- 根目录快捷方式为创建者个人入口，仅本人可见；工作区负责人不读取其他人的个人快捷方式或访问历史。共享文件夹中的快捷方式按其所在目录的当前访问权限展示，且必须同时有权读取目标及目标原始祖先链。链接所在目录不成为目标的新父级；打开内容继续使用原资源的完整权限，SELF 保持 createdBy 语义。
- 添加根目录快捷方式要求当前可读取目标；添加到文件夹还要求目标文件夹有效 MANAGER。普通员工可整理自己的根目录快捷方式，不获得新建共享文件夹或管理目标的权限。同一人根目录、或同一共享文件夹中，相同目标只有一个有效快捷方式。
- 移除快捷方式只移除引用，不修改目标、权限或历史记录；根入口仅创建者可移除，文件夹入口要求当前目录 MANAGER。允许有权管理链接位置的人移除已失效目标的链接，不返回目标名称/ID；移除采用软标记，以便重新鉴权后重放幂等收据，重复操作不增加审计。
- 目标改名/移动后链接显示当前名称、路径；自身或任一目标祖先回收/撤权后，列表、搜索、计数及链接解析均隐藏/拒绝目标。链接所在目录回收后也不可访问。恢复按当前权限重新计算，不恢复旧授权。
- 文件夹移动/回收/恢复会带动其中链接的位置可用性，不移动或回收链接指向的目标。整树 500 资源上限及预览摘要纳入有效链接，预览只显示操作者可见链接数量，目标内容数量不能重复计算。链接的目标不需要 MANAGER，原目录管理能力足以整理引用。

## 最近访问

- DriveVisit 以 userId + nodeId 唯一；目标打开通过鉴权后，由界面调用显式访问端点记录服务端时间。列表轮询、搜索、SSE、预览和后台刷新不记录访问；同一编辑器内切换视图/表不重复登记 Base。直链进入 Base 也登记；快捷方式登记原目标，去重为一条。
- 每人每工作区保留最近 100 个原资源，按服务端访问时间倒序；支持个人清空本工作区历史。日志写入失败不阻断正常打开，下次进入再记录。访问列表仍先检查当前权限/回收状态，再计算数量与分页，不能返回失效目标的历史名称或占位行。
- 个人访问写入采用个人范围锁和工作区共享锁，不更新目录/Base 修改时间、版本或公共协作事件，不在每次记录保存/查询的热路径写历史。个人记录不是审计事实；清空只删除自己的访问状态，不删除业务内容。

## API 与界面

- GET /workspaces/:id/drive 增加 scope=shortcuts/recent；普通目录包含本人根链接或目录中的共享链接。链接 DTO 显式区分入口 id 和原 targetId/targetKind，原资源名称、路径均即时鉴权解析；无权条目在分页/统计之前移除。recent 默认按 visitedAt 倒序，也保留名称排序和搜索。
- POST /workspaces/:id/drive/shortcuts：targetId、parentId（null 为个人根）；使用 Idempotency-Key。GET /drive/shortcuts/:id 解析可访问目标；POST /workspaces/:id/drive/shortcuts/:shortcutId/remove 移除引用并写一次审计。
- POST /drive/nodes/:id/visit：空对象及幂等键，仅使用当前账号；POST /workspaces/:id/drive/recent/clear 清空本人当前工作区访问记录。
- 左侧增加“快捷方式”“最近访问”；资源菜单添加“添加快捷方式”，顶栏提供独立“添加快捷方式”按钮，新建菜单也保留同名入口，支持选择有权目标和存放位置。链接带独立图标标记与“移除快捷方式”，不复用目标的移动/回收按钮，界面明确移除不会删除原资源。
- 最近访问显示“访问时间”，允许清空；三个入口打开同一个 Base 并保持返回入口/查询/布局。共享链接失权后 5 秒内随目录刷新清除，打开前再次鉴权。选择窗口中目标/目录失权也需移除旧选项；失败显示可重试提示，同一未完成请求保持幂等键。

## 实施与验收

1. 增量迁移两个模型、关系、索引与同区约束；兼容 G2-A 回收和恢复。先测试私有状态隔离、双路径授权、重复/并发/幂等、移除不影响内容、目标改名/移动/撤权/回收、历史清空/上限/不改变版本与事件。
2. 实现云盘创建/移除/解析/最近访问和编辑器直链登记。真实浏览器覆盖员工与负责人、共享链接指向同一记录、隐藏无权资源、失效会话、网络重试以及 1440/1024/390 布局。
3. 运行原协作/G1/G2-A 服务与完整 HTTP/浏览器回归、相关前端测试、两端 lint/类型/构建、baseline/bootstrap/docs 检查。对 500 目录资源和混合链接/访问记录执行目录性能回归。本期不改变记录查询/保存、tableAccess、folderChain 或 SSE 热路径，已有 100 会话/900 秒验收保持历史证据，不把它宣称为本次重跑；如实现确需修改热路径则重新运行原负载。
4. 两个隔离测试库及开发库仅增量迁移，恢复开发服务，更新 MOD/FTN/TRACE 和任务状态，提交本地 Git。
