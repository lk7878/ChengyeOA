## 实现

- 先完成规格，再修改实现。“关联财务”由整页 `href` 改为 React Router `Link`，避免在模块切换时丢失内存登录状态。
- OA 所有声明式 Modal 统一使用 `DraggableModal`：标题栏拖动、可达范围限制、窗口缩放约束、关闭重开复位，大表单内部滚动。回归发现 rc-dialog 隐藏时缓存子节点，已通过打开周期计数修复旧位置复用问题。
- 完整建档字段以经过白名单校验的 `Case.intakeData` JSONB 保存，保留原字段；货币使用十进制字符串，比例范围0–100%，日期和枚举严格校验。主办律师及客户在前后端必填。
- `CaseFile.category` 保存合同附件、收款凭证、退款凭证用途，案件与文件记录同事务创建；失败清理本次落盘文件。单次最多20个附件、合计10MB，请求解析上限16MB以容纳base64。
- 案件表单采用两列分组和独立滚动，详情回显全部新增字段和系统时间。部门来自启用部门；原财务流水不因建档补充信息自动变更。
- 客户支持远程搜索，输入姓名后跳转客户管理预填弹窗；成功或取消均可返回案件草稿，成功自动选中客户。附件 File 对象及草稿只存内存，关闭案件或退出账号后清理。
