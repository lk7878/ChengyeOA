# V1.2.1 智慧办案原生浮动工作台实施验收

依据 [SPEC-AI-UI-20260912](../specs/2026-09-12-smart-case-native-ui.md)。先建立原生 UI Spec，再按用户两次补充修订为浮动工作台、右上角单一入口。

## 结果

- OA 右上角“智慧办案”与“知识库”相邻，移除 OA 左侧菜单和临时设计的右下角入口；旧链接可以继续唤起窗口。
- 全局单实例浮动工作台放在 OA 路由之外，支持移动、缩放、最小化、最大化、窄屏适配及键盘操作。最小化和路由切换不卸载原生根；关闭、权限撤销或退出才清理连接。快速关闭再打开会等待上一工作区释放 OPFS 锁。
- 直接复用 Harness 的 AppFrame、SidebarRoot、ConversationRoot、InputBar、UserMessageNodeView、AssistantMarkdown、ApprovalPanel、QuestionComposer、图标、CSS 和中文词典。独立 React 18/ShadowRoot；原生弹层通过适配器留在同一主题内，原 C33 与导入快照源码均未改动。
- 本机文件、备份、知识库引用和 OCR 授权保留。窄窗口材料以对话框提供，宽窗口使用原生布局右栏。只将 source.kind=user 的原生事件呈现为律师气泡，模型上下文仍保留在原生日志，不显示为用户输入。
- 修复导航函数随路由变化导致办案根重建的问题；本次不改变数据库、权限码、IPC 协议或云端数据归属。

## 验证

- 独立浏览器构建通过，构建清单强制包含原生布局/侧栏/对话/输入/消息组件；知识库仍独立于办案外壳。9267 个快照文件指纹验证通过。
- OA 前端 typecheck、lint、生产构建通过；仍有既有 Notification/User 的 2 个 Hooks 警告和既有大分块提示。
- 前端全量 60 文件、303 项首轮有 302 项通过、1 项失败（窄屏布局条件渲染移除了既有面包屑测试所需节点）。改为响应式样式隐藏、保留原面包屑节点后，相关 Layout/CaseWorkbench 两文件 10 项全部通过；没有重跑无关的 302 项。
- 新增组件回归验证最小化、OA 路由切换保持同一个根、明确关闭清理、权限撤销卸载；现有 Layout 回归覆盖入口与品牌。
- 原生云端 Wiki 与实际浏览器 OPFS/原生 SDK 回归通过：检查点先落盘再调用模型，文书审批与保存、取消、刷新/恢复、文件解析和无个人云端持久化继续通过。
- 实际 Edge 浏览器通过：右上入口、左栏不重复、原生欢迎区/会话侧栏/输入框、输入法不误提交、失败保留输入、材料导入/恢复、跨页面最小化恢复、侧栏折叠、最大化/还原、较窄窗口、原生问题选择、原生保存审批、Markdown 表格、材料右栏、备份下载、拖动和键盘缩放、快速关闭再打开。
- 浏览器测试使用临时目录和本地 TLS 脚本模型，实际复用 Harness 提问、工具审批及文件保存链路；不发送到外部模型，不把 UI 测试结果当成真实法律答案质量验证。已检查欢迎、问题、审批、会话、材料与窄窗口截图。
- 最终 261 个独立静态产物与 OA 生产目录逐文件一致；本次 30 个变更文件的 Git 暂存内容经 Gitleaks 8.30.1 扫描，无告警。原 C33 HEAD、状态与差异指纹保持不变。
