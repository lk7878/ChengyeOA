# 成果文件右键同步 OA

文件卡片的原生右键菜单新增“同步OA工作空间”。适用于任务工作区 reports、drafts 内的成果文件；点击后确认当前文件版本和保存位置，再保存到承业空间 → 我的资源 → 我的文件。

## 实现

- 通过 contextMenus 的 file 扩展点注册，不修改上游 Harness，不操作菜单 DOM。
- 使用现有 `/api/tasks/:id/outputs` 获取稳定版本，确认后仅将该文件的快照 key 提交给 `/api/tasks/:id/save`。
- 保留服务端任务归属、输入材料与知识库授权检查、文件路径隔离、内容哈希校验和上传幂等逻辑。
- 取消不上传；重复点击受忙碌状态保护；已同步的相同版本提示已保存；文件变化或权限失败显示原因。后续修改需要再次确认，不自动同步，不自动正式归档。
- 源码 `plugins/dsh-baiyou-brand/src/oa-file-sync.js`，运行 `node plugins/dsh-baiyou-brand/wrap-client.mjs` 更新纳入版本管理的客户端构建产物。
