# 管辖核验索引

核验日期：2026-09-14。以下为官方来源起点，不是完整法规数据库或永久有效的管辖表。每次办案需查后续修订及事实时点适用版本。

- [民事诉讼法（2023 年修正，法院公布全文）](https://www.gzhzcourt.gov.cn/upload/editor/file/2025/08/04/6388989731436328121054632.pdf)：所查版本标明自 2024-01-01 施行。核查第二章的级别和地域规则；普通住所、合同、专属、协议管辖条号须从当前适用原文读取，不能沿用旧稿编号。PDF 抓取不能提取文字时，寻找官方 HTML 文本或请求所需页面，不冒充已读。
- [最高人民法院调整中级法院第一审民事案件标准的通知，法发〔2021〕27号](https://www.court.gov.cn/fabu/xiangqing/324151.html)：自 2021-10-01 实施。所查通知依据当事人住所组合区分标准，并明确若干案件类型不适用；因此移除参考技能按省份列出的旧通用金额表，实际分析须读全文和后续规定。
- [涉外民商事案件管辖若干问题的规定](https://www.court.gov.cn/shenpan/xiangqing/379181.html)：自 2023-01-01 施行，存在范围例外及集中管辖安排；不得套用普通国内民事标准。
- [基层法院第一审知识产权案件标准通知](https://www.court.gov.cn/fabu/xiangqing/355831.html)：用于查找知识产权专门安排，继续核对案件类型、清单和后续调整。

还需按案情核验高院级别标准、特别程序、仲裁法适用版本及拟受理地法院公布的集中管辖/调整文件。没有取得相关资料就明示该部分未核验，不用本索引推断唯一结论。
