# 死亡案件：死因推定与尸检审查

已出现过本文件的 `<skill_content>` 后禁止再加载。本助手**不做法医解剖**，只审材料、推定死因、写第六章。不要再加载 `causation-analysis`、`opinion-writing`。过错与原因力用已加载的 `medical-fault-causation`；须先完成本 skill 再写第七章。

写入 `reports/review/notes.md` 的「损害/死因」节后，再 `fill_report(chapter=damage, text=..., is_death_case=true)`，与其他章同轮并行发出。

## 先分两路

| 材料 | 怎么定死因 | 固定声明 |
|------|------------|----------|
| 有系统尸检 | 以尸检为金标准；对照临床诊断写直接 / 根本 / 辅助或诱因、死亡进程。尸检与临床矛盾时说明取舍，优先病理所见 | 无额外声明 |
| 无尸检 | 必须按病历推定，**不得空过第六章**。直接死因（终末机制）→ 沿时间轴回溯根本死因 → 辅助因素与诱因 | 「以上死因系根据现有病历的临床推定，确定性低于系统尸检。」 |

禁止用「多器官功能衰竭 / 循环呼吸衰竭 / 心跳呼吸骤停」替代**根本死因**。院内死亡常见多因一果，须写清主次与先后，不要并列一堆终末状态。

证据优先级：检验 / 影像 / 护理记录 > 抢救记录 > 死亡讨论 > 病程主观分析。病程与护理矛盾时甄别，不替法官定伪造。

## 要不要尸检（只评技术后果）

《医疗纠纷预防和处理条例》第26条：对死因有异议的，一般应在死亡后 **48 小时内**尸检；具备冻存条件可延至 **7 日**。须近亲属同意签字；拒签视为不同意。**不同意或拖延超过时限、影响死因判定的，由不同意或拖延的一方承担责任**——写进 notes 与第六章，不擅自改写成法院赔偿比例。

未尸检仍可推定，但准确度不得写成与系统尸检等同。即使详剖仍可能找不到确切死因（如部分心源性猝死、喉痉挛等）时，可给**倾向性意见**并标明不确定性。

## 审尸检报告时看什么

1. 是否写清直接 / 根本 / 辅助或诱因，有无用终末状态顶替根本死因。  
2. 取材与特殊检查是否覆盖争议机制（见下表）；缺项写入待补充，不编造阴性。  
3. 毒物 / 血型 / 培养 / IgE 等结论是否与剩余药品、输液器具封存对应。  
4. 培养结果须与死后腐败菌鉴别；过敏性休克**未检出药物不能单独否定**（用量可极微）。

## 九类特殊死亡（只作核对，不写操作手册）

争议机制命中时，病历或尸检应能对上对应线索；对不上就在 notes 标「机制未验证」。

| 类型 | 材料里应对得上的线索 |
|------|----------------------|
| 麻醉相关 | 麻醉药及代谢物；椎管内麻醉查硬脊膜损伤与脑脊液浓度差；局麻入血查局部血管破口 |
| 输血反应 | 溶血/过敏/TRALI 与超量过快、污染相鉴别；血型复核；剩余血样+尸血培养 |
| 药物过敏性休克 | 喉头水肿、嗜酸浸润（与哮喘/寄生虫鉴别）；血清 IgE / 类胰蛋白酶；剩余药品 |
| 双硫仑样反应 | 头孢/甲硝唑等用药期间接触乙醇；血乙醇可极低仍能诱发；与过敏鉴别 |
| 输液发热反应 | 输后短时寒战发热；未输完/同批号液体及用具是否封存做热原 |
| 过度输液 | 入量>出量、急性肺水肿/全身水肿；不要只用「心衰」结案 |
| 院感 / 医源性感染 | 侵入操作前无感染指标、此后急转感染性休克；操作部位炎症+培养须防污染 |
| 预防接种 | 是否按疫苗特性留样、是否有多学科方案，缺则标待补 |
| 传染病 | 防护与病原送检是否合规；本助手不替代疾控结论 |

## 写入第六章

顺序：直接死因 → 根本死因 → 辅助/诱因 → 死亡进程 →（无尸检则固定声明）→ 拖延/拒做尸检对判定的影响。原因力仍走第七章，必须锚定本步已固定的根本死因，不得用流行病学「反正也会死」否定个案。
