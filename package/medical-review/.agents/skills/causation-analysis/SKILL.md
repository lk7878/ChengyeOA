# 因果关系论证（只补方法，不改六级表）

已出现过本文件的 `<skill_content>` 后禁止再加载。不要再加载 `fault-type-classification`、`opinion-writing`。六级+百分比、过错类型、第七章句式以已加载的 `medical-fault-causation` 为准，本 skill **不要另给一套百分比**。

过程写入 `reports/review/notes.md` 的「因果论证」节。用户未点名改稿则不动 `fill_report`；点名改第七章时只调一次 `fill_report(chapter=causation)`。

## 先定任务边界

| 谁 | 写什么 | 不写什么 |
|----|--------|----------|
| 鉴定辅助（本助手） | 事实因果：过错与已固定损害在病理生理上是否符合；原因力六级+百分比 | 法院赔偿比例、「承担×责」、责任程度 |
| 裁判者 | 法律因果与责任分担 | — |

先有**已固定的损害后果**（死亡：根本死因；非死亡：功能/伤残/错误出生本身），再问该过错对该后果有无事实因果。同一过错可对感染有因果、对终局伤残无因果，须拆开。

## 三特征（用来防写崩）

1. **复杂性**：多因一果是常态。拆：诊疗实质性过错、知情对选择的影响、自身疾病/隐匿病理、依从性、当时当地条件、医疗不确定性、体质。自身疾病可降低原因力，不能单独当免责理由。  
2. **排他性**：要证明「因与果在机制上符合」，不必排除所有无关并存病（肝囊肿等）。全面穷尽他因会写成不可知论。  
3. **盖然性**：鉴定采用高度盖然，不是科学必然。流行病学只作背景，**禁止**「反正晚期也死」直接否定个案。

## 三种检验（结论须同向）

| 检验 | 何时用 | 问句 |
|------|--------|------|
| 如果没有（but-for） | 默认先做 | 规范诊疗后，该损害是否避免、推迟或减轻？ |
| 实质性因素 | 多因都能单独致损、but-for 失灵时 | 该过错是否可识别地改变了病程？ |
| 盖然性 | 窗口/获益本身是概率时 | 结合当时规范与本案证据，达到鉴定采用的盖然标准了吗？ |

多充分原因时不要因「没有它也可能死」就写成无因果。信息不足写「（待补充）」或认定性低档，不要硬定完全原因。

## 六级只按 7.3 选，不另给一套锚点

定档以已加载的 `medical-fault-causation` 为准。要点：轻微是「诱发或轻微促进、加重，没有过错通常仍难以避免」；次要是「促进或加重，没有过错，损害仍然有较大的可能会发生」；同等是两边缺一通常都不发生、难分主次；主要是「没有过错，损害一般不会发生」；全部是「没有过错，损害必然不会发生」。禁止用「不会如此恶化」「几乎必然」「作用很小」替换上述句子。（一）按过错写机制、不写百分比。报告（二）写自身疾病因素与各医院整体医疗过错的百分比；同一档用一个等级，相邻两档可写成「轻微至次要原因」。

机会丧失：第四章只描述具体丧失的机会，不机械换算百分比；**第七章仍须**写六级+百分比（窗口短或获益不确定从低），不要用「只写机会丧失、不定原因力」空过第七章。错误出生的果是错误出生本身，不是新生儿伤残。

## 用语：先认定，认定不稳再用排除

认定（由强到弱）：足以认定 → 可以认定 → 很可能成立 → 可能成立 → 难以成立 / 依据不充分 → 不能成立。  
排除：不能排除 / 难以排除 / 难以完全排除 → 可以排除 → 足以排除。  
「不能排除」不是主要原因的同义词。不要把原因力写成参与度或责任程度。

## 本工作台怎么落地（对应书上「四步」）

1. 机制与规范：已做的 `expected_care_plan` / `weknora_method`，标【出处：教科书/指南/共识】。  
2. 常识例外：用模型医学知识补「有无例外、能否避免」，未检索到的条款号标【医学常识】，禁止编造。  
3. 时序：按入院→关键决策→损害发生排事件，分医院；后院只评继续注意义务。  
4. 类案：最多 1 次 `weknora_cases`；只借思路，不借百分比。点名类案再加载 `case-recommendation`。

## 产出

`notes.md` 写：针对哪一损害 → but-for / 实质性因素 / 盖然 各一句 → 认定或排除用语 → 六级+百分比（与 `medical-fault-causation` 同一套）→ 自身 vs 医方区间约 100%。禁止输出鉴定咨询意见书。
