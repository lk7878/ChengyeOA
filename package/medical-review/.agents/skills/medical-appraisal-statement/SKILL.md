# 陈述意见书（点名才写）

已出现过本文件的 `<skill_content>` 后禁止再加载。不要再加载 `opinion-writing`、`fault-type-classification`、`causation-analysis`。默认主文书仍是七章 `fill_report`；本 skill **不改七章**。

输入优先：`reports/病历分析报告.md`，其次 `reports/review/notes.md`。尚无报告则先按规划出七章，再写陈述。与原件冲突以原件为准。禁止再 `parse_records`、禁止整本 `convert_file`。

## 筛选

一家医院一份；同一医院多次住院**不拆**。合并重复观点。删除仅形式瑕疵、与损害无关或证据不足项。病历缺陷仅在影响查明事实、连续性或患方权益时单列。拟行 ≠ 已做。

不写原因力六级+百分比，不写法院赔偿比例，不承诺「全部责任」或「承担×责」。不要另开「因果关系与原因力」专章。

## 结构（`body` 必须按此）

1. `# 患者姓名案`  
2. `## 陈述意见书`  
3. `各位鉴定人、临床医学专家：`  
4. **一段**整体诊疗过程（入院原因→各院要点→转归→损害），即使本份只评一家  
5. 患方：「现患方认为，××医院在诊疗过程中存在以下过错：」；医方作对应答辩起句  
6. `### 一、……` 标题即结论；二级用（一）（二）连续段落，不要「发现问题 / 病历依据 / 指南依据」标签  
7. 过错写完后直接收束 + `提交人：` / `年   月   日`

过错主体只写本份医院。规范用报告里已列出的名称与要点，不要为本 skill 再检索。事实后附【文书类型，第N页】。人称「患者」。非死亡收束不得写死亡。

患方收束（把损害填具体）：

「综上，患方认为××医院上述医疗过错行为与患者发生【最终损害后果】之间存在因果关系，恳请各位鉴定专家公允鉴定。」

医方收束：

「综上，医方认为针对××医院的诊疗，患方所指过错不能成立，或与患者【最终损害后果】无事实因果关系，恳请各位鉴定专家公允鉴定。」

## 调用

一次一家：`fill_statement(patient_name, hospital_name, stance, body)`。`stance` 为 `患方` 或 `医方`（默认患方）。多家分别调用。写完 `present` 对应 md。不要出鉴定咨询意见书。
