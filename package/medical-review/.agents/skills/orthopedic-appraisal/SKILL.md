## 骨折主导（四类共用）

原发外伤（粉碎、关节面、移位、软组织、血运）往往已经定下功能预后上限。即使规范手术也可能残留障碍——这只说明医方原因力**常偏低**，必须本案 but-for，**禁止把「次要」当默认抄进第七章**。

再问医方是否**额外加重**：复位/固定是否明显偏离当时规范、是否漏诊延误、闭合性骨折术后感染是否与无菌操作时间空间符合、内固定是否构成稳定系统。告知不足单独一般不当然等于坏死或僵硬的主因。患方自行负重、松外固定、不复诊单独评价。拟行 ≠ 已做。

## 先定哪一类（只评一类）

| 类 | 何时用 | 先看什么 |
|----|--------|----------|
| 骨折后神经损伤 | 术后新发麻木/肌力下降，或术前已有神经症状 | 术前是否已有体征；术后即刻 vs 数小时后加重；术中是否探查保护；内固定是否压迫；发现后是否及时肌电/探查 |
| 股骨头坏死 | 髋部骨折/脱位或激素后坏死 | 坏死时点相对手术；头下型/移位/脱位的血运风险；复位固定是否额外伤血运或骨骺；激素指征与告知 |
| 关节功能障碍 | 骨折后僵硬、创伤性关节炎、关节置换 | 是否累及关节面；复位固定质量；漏诊时长；闭合骨折术后感染与术野符合性 |
| 钢板断裂 | 内固定断裂、骨不连、二次手术 | 固定方式/螺钉/植骨是否构成稳定系统；骨折是否已愈合；再次外伤或材料缺陷；患方负重与复诊 |

对不上上表就停，回到方法库。主损害是关节僵硬、交叉普通外科感染原则时仍走本 skill，不要再开 `surgical-appraisal`。

## 各类审查（只填本案有证据的项）

**神经**：术前已有 → 原发伤为主，医方只评发现与处理。术前无、术后即完全瘫 → 医源性直接损伤符合性强，可上调。术后渐重 → 血肿/石膏等继发压迫，看观察是否及时。「不排除术中损伤」不是主要原因的同义词。残留功能另评残。

**坏死**：愈合好、后期才坏死、取出术在关节囊外 → 倾向骨折并发症，告知不足另列。复位差、固定伤骨骺/血运、多项叠加 → 可上调。激素：适应证、疗程、个体易感与告知分拆，短期规范使用且告知充分可无因果或极低档。

**关节**：累及关节面时，即使理想手术也可残留障碍，过错多为加重因素。螺钉进关节、明显复位失败、可避免的闭合骨折术后感染，符合性更强。多发伤掩盖漏诊可降档，仍须写清延误了什么。

**钢板**：未愈合即断，先看固定是否稳定（方式、间隙、螺钉穿过对侧皮质、粉碎是否植骨）。原发高能量粉碎可降档。已愈合后断裂考虑疲劳或再损伤。方案「非最优」单独一般从低。
