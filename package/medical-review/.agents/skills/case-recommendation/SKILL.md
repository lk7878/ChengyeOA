# 类案对照（只对照，不套结论）

已出现过本文件的 `<skill_content>` 后禁止再加载。不要再加载 `fault-type-classification`、`causation-analysis`、`disease-appraisal-guidelines`。过错与原因力口径用已加载的 `medical-fault-causation`。本 skill **不改七章**，除非用户点名把对照写进第七章。

过程写入 `reports/review/notes.md` 的「类案对照」一节。库是「脱敏案例库」（教学案例，不是判决先例）。

## 怎么检索（本会话最多 1 次）

先从本案抽出三元组，再检索，禁止空词、禁止连打：

`{主诊断或术式, 主过错类型, 预估原因力档}`

一次 `weknora_cases`，最多 2 个检索词，例如：`腹腔镜 胆管损伤 主要原因`、`错误出生 知情告知`。未命中可改写成疾病大类+过错大类再试 **0 次以外不再加打**——改词也算在「最多 1 次」里（即首次未中则本轮放弃类案，用本案 but-for 收口）。

匹配只作排序，不升格为判例：

| 精确度 | 条件 | 用法 |
|--------|------|------|
| 完全 | 疾病+过错+原因力档都接近 | 优先对照论证思路 |
| 部分 | 两维接近 | 必须先写差异再谈方向 |
| 参考 | 仅一维接近 | 只借方法，不借档位 |

过错类型用：诊断 / 用药 / 手术 / 过度医疗 / 知情告知 / 机会丧失 / 病历书写 / 其他。原因力档用六级（无因果关系 0–4 / 轻微 5–15 / 次要 16–44 / 同等 45–55 / 主要 56–95 / 全部 96–100）。档位按 7.3 反事实选定，**百分比仍须由本案单独论证**，且不得跨档。

## 八维差异（每个命中案各填一行）

| # | 维 | 高于 / 等于 / 低于参照 |
|---|----|------------------------|
| 1 | 疾病/术式/分期 | |
| 2 | 过错类型与子类型 | |
| 3 | 过错严重程度（环节多少、偏离大小） | |
| 4 | 自身疾病、合并症、延误就诊 | |
| 5 | 损害后果（死亡 / 伤残 / 功能障碍 / 错误出生本身） | |
| 6 | 紧急程度与时间窗 | |
| 7 | 当时医疗机构条件（「当时的医疗水平」） | |
| 8 | 证据（尸检、影像、客观记录是否完整） | |

方向口诀（只调档位方向，不抄百分比）：过错更重或自身因素更轻 → 原因力**上调一档倾向**；自身因素更重、疾病预后本就极差或过错更轻 → **下调一档倾向**。证据更充分只提高置信，不自动加档。多家医院分别对照，不把参照案的跨院比例搬过来。

## 禁止

- 「按该案 / 先例 / 完全相同」；把库内 d%–e% 写入 `fill_report(chapter=causation)`。
- 用案例年代分布或 59 案统计推断全国规律。
- 知情告知瑕疵的参照案直接当成诊疗过错的原因力。
- 未做八维差异就引用。
- 引用时不标【出处：脱敏案例库 / 检索词】。

正确写法：「与检索到的××案在术式上接近，但本案自身因素更重，原因力宜低于该参照的论证档，本案仍按 but-for 定为××（d%–e%）。」

## 产出

`notes.md` 写：三元组 → 命中几条（完全/部分/参考）→ 各案相似点≥1、差异点≥1 → 对本案原因力的**方向建议**（上调/持平/下调）→ 明确「百分比以本案第七章为准」。默认不调用 `fill_report`。
