# 过错类型与原因力

已出现过本文件的 `<skill_content>` 后禁止再加载。不要再加载 `fault-type-classification`、`causation-analysis`、`opinion-writing`（点名才由规划表加载）。损害后果以同轮的 `damage-consequence` 为准，先定果再挂因果。

过程写入 `reports/review/notes.md` 的「过错/原因力」节。波次 D 先加载 `medical-report-writing`，再 `fill_report(chapter=causation)`，与其他六章同轮并行发出。原因力口径以本 skill 为准，章内句式以写作 skill 为准。禁止表格。不要和第六章挤在同一次调用里。禁止自拟「but-for检验」「原因力分析」作标题。

注意义务用波次 C **已做的** `weknora_clinical` + `expected_care_plan`（教科书>临床指南>专家共识）+ 医学常识；法律用已做的 `weknora_law`；模板用已做的 `weknora_method`；伤残用已做的 `weknora_search`；类案最多 1 次 `weknora_cases`。标【出处：临床知识库 《指南名》】。禁止为本 skill 再连打检索或再调 `expected_care_plan`。类案不得当判例，不得抄其百分比。`expected_care_plan` 写明不适用于本案的指南，不得再当过错依据。

## 过错（择一主类型，可并列次类型）

| 类型 | 子类型（择一） | 认定要点 |
|------|----------------|----------|
| 诊断 | 错误诊断；延误；漏诊并存或新发；病因判错；性质/程度判错 | 当时资料足以作出或修正而未作，且改变后续路径。延误不以时长唯一标准 |
| 用药 | 品种/性质错；途径剂量配伍疗程错；ADR 观察处置不当 | 无适应证、禁忌、剂量疗程或观察明显偏离当时规范。合格药常规用量下的 ADR 本身不是过错 |
| 手术/操作 | 无指征；方式不当；时机过早/过迟；术中偏离；围术期观察处理不当 | 偏离须参与损害机制。「不排除操作错误」不是主要原因的同义词 |
| 过度医疗 | 过度检查；过度治疗；过度护理 | 无适应证或无增量获益，并造成可避免伤害或费用/风险 |
| 知情告知 | 病情；措施/替代方案；风险；尸检建议；告知对象错误 | 应告知未告知或告知不充分，且影响选择；签字 ≠ 真告知。单独一般不当然等于诊疗主因 |
| 机会丧失 | 丧失生存/康复机会；错误出生/错误受孕 | 窗口可实施 + 无正当禁忌 + 未评估/未实施/未告知替代，三者同时成立。第四章只描述具体丧失的机会；**第七章仍须写六级+百分比**（窗口短或获益不确定从低） |
| 病历书写 | 不客观；不真实；不准确；不及时；不完整；不规范 | 仅当影响查明事实、连续性或患方权益时单列；纯形式瑕疵不入意见；不替法官定伪 |
| 其他 | 转诊会诊；观察与抢救组织；院感；护理；设施/管理 | 能归入上列就不要用兜底。设施/门锁/后勤单独列，不与诊疗过错打包 |

并发症 ≠ 过错。拟行 ≠ 已做。有过错无对应损害 → 原因力为无。自身疾病可降档，不能单独免责。患方拒治、隐瞒、自行出院单独评价。医院等级不能消灭基本注意义务。子类型点名再加载 `fault-type-classification`。

抗凝、溶栓、手术：必须先写当时禁忌与可实施性。活动性出血、血胸、创伤未稳定时，不得仅因事后发生血栓就认定「应当药物预防」。评分量表未在检索中给出计分规则时，写「具体分值有待核实」，禁止自造分值。

## 事实因果（本助手只写这一层）

鉴定人写：过错与**已固定的那一项损害**在机制上是否符合，以及原因力。不要写法院赔偿比例、「承担×责」、责任程度（那是裁判者的法律因果）。

同一过错可对感染有因果、对终局伤残无因果，须分项。错误出生的果是错误出生本身。禁止「反正晚期也死」直接写无因果。设施缺陷若成立，通常只挂「抢救延误所致的损害加重」，不挂血栓形成本身。

每项过错先写**病理生理符合性**（为何该偏离能导向该损害），再做三种检验，结论须同向：

1. **如果没有（but-for）**：规范诊疗后，该损害是否避免、推迟或减轻？默认先做。写成句子，不要当小节标题。  
2. **实质性因素**：多因都能单独致损、but-for 失灵时，该过错是否可识别地改变了病程？  
3. **盖然性**：窗口/获益是概率时，是否达到鉴定采用的盖然标准？

死亡案须已完成死因推定（未加载则加载一次 `autopsy-guidance`）。不用终末状态替代根本死因。

文献或流行病学「预防可降低 x%」只作背景，**禁止**写成「本案若预防则大概率可避免」的个案数字。证据不足时不得升档。证据已经达到「若没有该过错，损害必然不会发生」时，不得因全部原因少见而降为主要原因。

认定用语由强到弱：足以认定 → 可以认定 → 很可能成立 → 可能成立 → 难以成立 / 依据不充分 → 不能成立。「不能排除」不是主要原因的同义词。

## 原因力六级（先按 7.3 定性，再落百分比）

六级只评价**某一医疗行为与某一项已固定损害**的事实因果，不是法院责任比例。先写反事实，再选定唯一等级，最后把百分比整段落进该档。禁止先写百分比再贴标签，禁止为了和自身因素加总成 100% 而改档。

对照因素是：患者原发疾病、高龄、自身健康状况和体质。过程稿按过错写机制，不在单项过错上写百分比。报告第七章（二）必须单列「自身疾病因素（……）：约占a%-b%（等级）。」

| 条款 | 等级 | 百分比必须整段落入 | 法定反事实（同一条必须出现这一句，不得改写成相邻档的句子） |
|------|------|--------------------|--------------------------------------------------------------|
| 7.3.1 | 无因果关系 | 0%–4% | 不良后果几乎完全由上述对照因素造成，与该医疗行为不存在本质上的关联 |
| 7.3.2 | 轻微原因 | 5%–15% | 损害从本质上由对照因素造成；过错仅起诱发或轻微促进、加重作用。即使没有该过错，损害通常情况下仍然难以避免 |
| 7.3.3 | 次要原因 | 16%–44% | 损害主要由对照因素造成；过错起促进或加重作用。即使没有该过错，损害仍然有较大的可能会发生 |
| 7.3.4 | 同等原因 | 45%–55% | 损害与该过错及对照因素均密切相关。若没有该过错，或者没有对照因素，损害通常情况下都不发生。两边作用基本相当，难分主次 |
| 7.3.5 | 主要原因 | 56%–95% | 该过错是损害的主要原因，对照因素只起次要作用。若没有该过错，损害一般不会发生 |
| 7.3.6 | 全部原因 | 96%–100% | 该过错是损害的直接原因。若没有该过错，损害必然不会发生 |

相邻档不得混用：

- 「诱发或轻微促进、加重」且「通常情况下仍然难以避免」只能是轻微原因，禁止写成次要原因。
- 「促进或加重」且「没有该过错，损害仍然有较大的可能会发生」是次要原因。禁止把「不会如此恶化」「起到不利影响」升成主要原因。
- 「若没有该过错，损害一般不会发生」且对照因素只起次要作用，才是主要原因。禁止用「很可能不会发生」「决定性」「直接原因」描述主要原因。
- 「必然不会发生」且过错是直接原因，才是全部原因。禁止写成「几乎必然」，禁止降为主要原因。
- 与该医疗行为不存在本质上的关联，才是无因果关系。某院「根据现有材料，未发现明显不当」是未认定过错，不要写成 0%–4%。有过错但与该损害无对应，才用无因果关系。
- 过程论证区分相邻档，不要把轻微论证写成次要。报告（二）里，医院整体过错若介于相邻两档，写成「轻微至次要原因」及覆盖这两档的区间，如 5%-30%。禁止跨越不相邻档，如 5%-95%、主要至完全。

不抄类案百分比，不把文献「预防可降低 x%」写成个案原因力。信息不足写「（待补充）」，不要硬定全部原因，也不要为求稳压到次要或轻微。

多家医院：同一医院多次住院不拆；先院内，再跨院。后院对前院造成的局面只评继续注意义务。（一）仍按过错写机制。报告（二）每家医院只写一条「医院名称整体医疗过错」，不要按单项过错各写百分比，也不要把多家医院合成「医方」。自身疾病与各医院区间应对应，两端相加宜为 100%。论证用语点名再加载 `causation-analysis`。

## 第七章写法

（一）按医院写过错与事实因果。每项采用「病历事实—规范要求（含是否适用本案）—过错分析—机制符合性」，附【医院名称，文书类型，第N页】。无过错的医院写「根据现有材料，未发现明显不当」。本节不写约占百分比。  
（二）标题为「因果关系及原因力初判结果及参考依据」。开篇只写：「综合考虑患者原发疾病及医院的医疗过错，对损害后果的原因力初步划分如下：」然后用「• 」两条（多家医院则医院各一条），不写法定反事实原句：  
• 自身疾病因素（高龄、具体原发疾病等）：约占70%-95%（主要原因）。  
• 医院名称整体医疗过错：约占5%-30%（轻微至次要原因）。  
区间用半角连字符。同一档写（主要原因）；只允许跨相邻两档并写成（轻微至次要原因）。随后写备注：医学层面初判提供责任划分和赔偿比例参考，但不直接等同于法律责任比例；并给院内/医调委协商或诉讼路径建议。死亡未尸检须另写死因判断局限性及诉讼风险。

不要出鉴定咨询意见书。
