# 意见书对表（只对表，不另出文书）

已出现过本文件的 `<skill_content>` 后禁止再加载。不要再加载 `causation-analysis`、`fault-type-classification`。本助手**不是鉴定机构**，不签发鉴定意见书、不出鉴定咨询意见书、不代行回避/终止决定。默认主文书仍是 `reports/病历分析报告.md`。格式点名再加载 `medical-report-writing`；审已有意见点名再加载 `appraisal-review`。

过程写入 `reports/review/notes.md` 的「意见书对表」节。未点名改稿不动 `fill_report`。

## 书上八部分 → 本工作台七章

| 书上部分 | 落到哪 | 本工作台怎么做 |
|----------|--------|----------------|
| 基本情况 / 基本案情 | overview + 标题姓名 | `fill_report` 第一章带 `patient_name`；重鉴焦点写入 notes，不另开文书 |
| 资料摘要 | overview / integrity | 围绕争议摘录，禁止整本照抄病历；第二章标题为病历合规性分析 |
| 鉴定过程 / 方法 | notes + 各章【出处】 | 位阶：教科书 → 临床指南 → 专家共识。标【教科书/指南/共识 年份 / 医学常识】 |
| 分析说明 | diagnosis / treatment / consent / damage / causation | 先定果再因果；原因力六级+百分比，不是赔偿比例 |
| 鉴定意见 | causation（二） | 正面回答委托式问题：过错是否成立、与哪一损害有事实因果、原因力档 |
| 附件 / 落款 | 不由本助手完成 | 不伪造鉴定人签名、不盖章 |

分析说明盯十问（只填本案有证据的）：利益、风险、有无替代、替代的利弊、是否当时较佳、告知是否充分、是否过费、是否合当时规范、实施者能力与风险防范。演绎自洽，或然结论必须说明。不替法官写责任程度。

## 材料五性（受理/合规性章用）

| 性 | 不合格信号 |
|----|------------|
| 符合性 | 与委托事项无关；死亡案无死因材料且病历无法推定 |
| 完整性 | 缺外院、缺影像/病理原件、无法再现关键操作 |
| 充分性 | 胶片毁损、关键阴性未记、不足以作盖然判断 |
| 关联性 | 把无关科室病历当本案依据 |
| 真实性合法性 | 单方未质证材料当唯一依据；替法官定篡改 |

矛盾按审查 skill 三原则取舍。材料不够写「（待补充）」或建议委托人补，不编造。

## 程序（只评技术后果，不做裁定）

方法须适时、最接近专门问题、非动物实验直接外推、注意案发地当时要求。同学师生不是法定回避，有利害关系写入 notes 即可。本助手不决定延期、终止、出庭。用户问「这份写得合不合格」→ 改加载 `appraisal-review`，不要用本 skill 开写。

## 红线

禁止输出鉴定意见书或鉴定咨询意见书全文。禁止把原因力写成「承担×责」。拟行 ≠ 已做。七章正文禁止 Markdown 表格。
