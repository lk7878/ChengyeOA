# 疾病鉴定路由

已出现过本文件的 `<skill_content>` 后禁止再加载。不要再加载 `fault-type-classification`、`causation-analysis`、四个专科 skill 里**未选中的那几个**。过错与原因力用已加载的 `medical-fault-causation`；损害用 `damage-consequence`。本 skill **不改七章**。

过程写入 `reports/review/notes.md` 的「疾病模板」一节：命中哪条路由、是否再加载专科 skill、方法库检索词。

## 先检索，再决定要不要专科 skill

波次 C 读完主诊断/术式后加载本文件一次选路。  
默认仍要做一次 `weknora_method(queries=[疾病或术式+过错, 过错子类型, 原因力方法, 争议点])`。  
命中下表则**最多再加载一个**专科 skill；对不上 21 类就停在通用七步 + `expected_care_plan` + 方法库，禁止四个专科连开，禁止把书内「典型原因力」写入本案。

围手术期 VTE、感染、心肺意外等对不上四类骨科/七类手术模块时，按「术后观察/预防」审查，必须先核对预防指南是否适用于该术式，不得把髋膝关节置换或髋部骨折的「骨科大手术」规范直接套用于锁骨、上肢手术。

## 路由（命中一行即停）

| 专科 skill | 疾病 / 术式 | 症状或争议线索 |
|------------|-------------|----------------|
| `surgical-appraisal` | 甲状腺手术；PCI/支架；腹腔镜（胆囊/妇科/肠粘连）；子宫切除；脊柱内固定；全麻拔管转运；椎管内麻醉 | 术后声嘶/低钙；穿刺出血；胆漏/肠漏/阴道流液；拔管后窒息 |
| `obstetric-appraisal` | 死胎；脑瘫；新生儿窒息；肩难产臂丛损伤；错误出生 | 胎心异常、催产素、Apgar 低、产前筛查漏诊缺陷儿 |
| `emergency-appraisal` | 主动脉瘤/夹层；急腹症/ERCP；脑卒中溶栓；暴发性心肌炎；病理诊断错误 | 撕裂样胸背痛；休克仍先做 CT；4.5h 窗口；消化道起病猝死；冰冻/外院病理与术中不符 |
| `orthopedic-appraisal` | 骨折后神经损伤；股骨头坏死；骨折后关节功能障碍；钢板断裂 | 术后新发神经损；髋痛坏死；关节僵硬；内固定断裂 |

交叉案只选**主损害对应的那一个**专科，另一条用方法库补一句，不再加载第二个专科 skill。例如：剖宫产+麻醉争议，主损害是脑瘫 → `obstetric-appraisal`；主损害是拔管窒息 → `surgical-appraisal`。

## 专科方法一口径（细则以专科 skill / 方法库为准）

| 专科 | 审查骨架 | 定果与原因力时记住 |
|------|----------|-------------------|
| 手术 | 七步：术前检查 → 指征时机 → 并发症预案 → 知情告知 → 术中操作 → 术后观察 → 预后告知 | 并发症 ≠ 免责；拟行 ≠ 已做 |
| 产科 | 三时段：产前因素 → 产时因素 → 产后因素 | 错误出生的果是错误出生本身，不是新生儿伤残 |
| 急危 | 三要素：诊断窗口 → 病程速度 → 机会丧失 | 疾病凶险只降原因力，不能单独免责；溶栓窗口可单列机会丧失，仍须写六级+百分比 |
| 骨科 | 骨折主导：原发损伤定功能上限，再评复位/内固定/感染/告知 | 医方过错常为次要，须本案 but-for，禁止抄「次要」当默认 |

减责只列本案有证据的：自身疾病/原发伤、症状极不典型且窗口极短、患方不配合、当时当地条件。医院等级不能消灭基本查体、生命体征和鉴别诊断义务。

## 禁止

- 用本表「典型区间」或 C3 编号当本案原因力。  
- 方法库已够仍加载专科全书。  
- 为路由再打 `weknora_method` / `weknora_cases`（沿用波次 C；类案点名才走 `case-recommendation`）。  
- 输出鉴定咨询意见书。
