## 注意义务（当时当地）

评价以行为当时同级同类医务人员的合理注意为限，校准三性：

1. **合理性**：当时资料是否足以作出该判断或处置。  
2. **时限性**：用行为发生时的规范，不要用事后新指南苛责。  
3. **地域性**：按医院等级校准复杂技术与设备依赖项目；生命体征、基本查体、危重症鉴别不因基层免除。

后见之明禁止：已知不良后果不能用来证明当时必然可预见。结果预见问四件事：能否预见、何时应预见、预见程度、是否属于当时医疗水平应当预见。结果避免看当时能否采取规范措施，或充分告知后由患者选择。

## 条目写法

**应然规范（含适用范围）→ 时间链与数值 → 实际处置 → 结论**。符合规范的对照也要写，不要只列问题。

拟行 ≠ 已做。同一医院多次住院不拆。患方拒绝/自动出院如实记载。机会丧失三要件（窗口可实施 + 无正当禁忌 + 未评估/未实施/未告知替代）缺一不可，原因力仍由 `medical-fault-causation` 写六级+百分比。

病历矛盾：他份材料印证则可采并说明理由；均无印证时对查明事实采对患者有利的理解；都模糊则标待质证。**不替法官定伪造/篡改**。

病程/入院「辅助检查」与影像报告不一致时，先怀疑解析串台，再怀疑书写错误：
1. 必须 `parse_records_query` 对应日期的 **影像报告** 原文，不能只信病程条目化列表或时间轴「影像」行。
2. 同一次检查在入院记录、首次病程、其他查房中的转述要对照。入院/首次病程/报告单三者一致，仅某一页列表把后一次 MRI 结论接到前一次 CT 名下 → 写「解析条目与报告单矛盾，待核原件」，**不得**写成病历书写过错。
3. `meta.md` / `parse-warnings.md` 已有「解析核验警告」时，禁止把警告内容直接抄成医方过错。
4. 「骨髓水肿 / 脊髓水肿」以影像报告用词为准；字形相近时优先怀疑 OCR，不得单凭病程解析稿认定误写。

## 同轮完成（禁止未取证就下结论）

1. **取证**：并行 `parse_records_query` 医嘱、手术/麻醉、知情同意、评分表原文、抢救/会诊、检验报告、影像报告、护理记录、首次病程。概要里的数值和经过以这些原件为准，不用出院记录或死亡记录代替。  
2. **合规性 / 时间 / 知情**：缺页、串页、麻醉与术式互斥、关键时限、同意书是否针对性签字；矛盾写「真实性疑问」，不替法官定伪造/篡改。  
3. **诊断**：先定性五亚型之一——错误诊断（甲当乙/有当无）、延误（不以时长唯一标准）、漏诊并存或新发、病因判错、性质/程度判错。再归因：患方病史不全、医方该查未查/解读错误、症状极不典型。当时资料是否足以作出或修正。  
4. **应然**：用波次 C **已发出的** `weknora_clinical` 原文 + `expected_care_plan`（教科书>临床指南>专家共识）。必须抄写其「指南适用范围」「禁忌与可实施性」。不在适用范围内的指南不得当应然。标【出处：临床知识库 《指南/共识》 年份】或【医学常识】。禁止为本 skill 再连打检索、禁止编造条款号或评分分值。伤残/病历书写才用已做的 `weknora_search`。  
5. **实然对照**：把医方已实施行为与应然方案逐项对照；符合的也要写。手术类按七步过一遍：术前检查 → 指征时机 → 并发症预案（无记录不能认定已有预案）→ 知情告知 → 术中操作 → 术后观察/预防 → 预后告知。可能过错写入 notes「对照/过错」节，原因力仍由 `medical-fault-causation` 写六级+百分比。只评已实施的用药 / 手术 / 抢救 / 观察 / 过度医疗 / 诊断闭环。抗凝、溶栓、手术必须写当时出血/禁忌是否允许实施。  
6. **损害**：按同轮 `damage-consequence` 写入 notes 损害节，本 skill 不重复评残或死因细则。

## notes.md 小标题（必须齐）

合规性 / 诊断 / 应然（适用范围+禁忌） / 实然对照 / 损害 / 过错分型 / 因果与原因力。不要写「小结」。
