# 损害后果（先定果，再谈原因力）

已出现过本文件的 `<skill_content>` 后禁止再加载。不要再加载 `causation-analysis`、`opinion-writing`。第七章用已加载的 `medical-fault-causation`，且必须锚定本步已固定的那一项（或几项）损害。

写入 `reports/review/notes.md` 的「损害」节。波次 D 先加载 `medical-report-writing`，再 `fill_report(chapter=damage, text=..., is_death_case=...)`，与其他六章同轮并行发出。损害口径以本 skill 为准，章内句式以写作 skill 为准。禁止表格、禁止「待补项」、禁止写原因力。

## 先定 `is_death_case`

死亡记录、死亡诊断、死亡讨论、尸检任一存在 → `true`。否则 `false`（含放弃治疗后院外死亡但材料只有住院经过时：有死亡事实仍为 `true`）。不要用「预后差」把存活病例写成死亡案。

非死亡：写最终损害后果 + 伤残初步评定（材料不足则写待补检查，不得空过）。不加载 `autopsy-guidance`。  
死亡：写最终损害后果 + 死亡原因初步分析（直接 / 根本 / 死亡进程；有尸检引尸检）。加载一次 `autopsy-guidance`（细则以它为准，此处不重复九类尸检）。

## 什么算本案损害（防选错）

写进第六章的必须是**医疗过程相关的人身后果**，不是费用单或情绪。常见选错：

- 把自身疾病、自然转归、筛查检出概率当成医疗损害。  
- 把**拟行未做**的手术写成已发生损害。  
- 错误出生：果 = **错误出生本身**（丧失产前发现并知情选择的机会），不是新生儿畸形/伤残/死亡。  
- 机会丧失：写清丧失了哪一窗口或选择；若同时有残留功能障碍，两项分列，评残只绑残留功能。  
- 同一过错可对感染有果、对终局伤残无果——分项列，供第七章分别挂原因力。

并发症可以是损害，是否有过错是另一步。材料不足列待补检查，**不得空过第六章**，不要单列「待补项」小节标题。

后见之明：不要把自身疾病自然转归写成医疗造成的最终损害；中间损害（感染、血栓、机会丧失）与终局功能/死亡分列，供第七章分别挂原因力。

## 非死亡：伤残方向

1. 「### （一）最终损害后果」用 180～300 字一个连贯自然段：原发疾病、并发症或继发损害、器官功能、后续治疗、自理与劳动能力及转归。只写有材料支持的事实。  
2. 有残留功能且治疗终结、伤情相对稳定时写「### （三）伤残初步评定」：用波次 C **已做的** `weknora_search` 对《人体损伤致残程度分级》等（这不是临床指南检索），给伤残等级意见或评残建议，标已核实条款。禁止为本步再单独打一轮检索；未命中标【医学常识】，不编条款号。  
3. 不够评残时写：「现有资料尚不足以进行伤残等级评定，建议待治疗终结、伤情稳定并完善××后再行鉴定。」  
4. 本助手是医疗损害框架内的方向认定，**不是**另开损伤鉴定案，不出具正式伤残鉴定书。  
5. 非死亡不要写死亡原因节。

仅主诉（疼痛、性功能、视力等）无客观记录，不得直接定残；可写「主诉××，目前缺乏客观固定依据」。

## 死亡：死因（摘要）

有系统尸检：以尸检为金标准，对照临床，矛盾时说明取舍、优先病理。  
无尸检：按病历推定，不得空过。直接死因（终末机制）→ 回溯根本死因 → 辅助/诱因。证据：检验/影像/护理 > 抢救记录 > 死亡讨论 > 病程主观。固定声明：「以上死因系根据现有病历的临床推定，确定性低于系统尸检。」第六章死亡案按模板写「### （二）死亡原因初步分析」，起句「根据现有病历资料对患者死亡原因可能性分析：」，再写直接死因为 A，根本死因为 B，死亡发展进程为 C。

禁止用「多器官功能衰竭 / 循环呼吸衰竭 / 心跳呼吸骤停」替代**根本死因**。拒做或拖延尸检超过时限、影响判定的，按《医疗纠纷预防和处理条例》第26条写清技术后果，不改写成赔偿比例。

## 产出与红线

`notes.md`：`is_death_case` → 损害清单（分项）→ 伤残意见或死因层级 → 待补项。  
第六章只定果。不要写原因力百分比、不要写「承担×责」。拟行≠已做。不要出鉴定咨询意见书。
