# 意见书 / 本报告审查（只审不写）

已出现过本文件的 `<skill_content>` 后禁止再加载。不要再加载 `opinion-writing`、`fault-type-classification`、`causation-analysis`。过错与原因力口径用已加载的 `medical-fault-causation`。默认出件走七章 `fill_report`，本 skill 不改章，除非用户点名改稿。

审查对象优先：`reports/病历分析报告.md`；用户提交的鉴定意见书/分析说明。中间结论只追加 `reports/review/notes.md` 的「意见书审查」一节。

## 先定审查范围

1. 是否已固定损害后果（死亡：死因层级；非死亡：功能/伤残方向 + 固定句）。
2. 第七章（二）是否为「自身疾病因素（……）：约占a%-b%（等级）」加「医院名称整体医疗过错：约占c%-d%（等级）」。同一档对应一个等级；相邻两档可写成「轻微至次要原因」（如 5%-30%）。不得跨越不相邻档，不得按单项过错拆百分比。
3. 有无把原因力写成法院赔偿比例或「承担×责」。

## 八项审查（逐项给「通过 / 问题 + 页码」）

| # | 看什么 | 不合格信号 |
|---|--------|------------|
| 1 | 损害未客观确认 | 仅主诉（疼痛、性功能、视力等）无检查/影像/功能记录即定损 |
| 2 | 损害选错 | 把自身疾病、筛查概率、未实施的拟行手术当成医疗损害；错误出生应定为错误出生本身，不是新生儿伤残 |
| 3 | 病历采用不当 | 矛盾材料未说明取舍；替法官认定伪造/篡改；单方采信无印证陈述 |
| 4 | 依据不适格 | 用错位阶、案发后新规范、动物实验、与本案术式/病种不接近的条文 |
| 5 | 越权 | 用资质名录、赔偿比例、「责任程度」改原因力；鉴定事项之外做法官 |
| 6 | 机械套统计 | 用流行病学/生存率直接否定个案因果（「反正晚期也死」） |
| 7 | 「当时的」规范用错 | 用过时或过新的共识；未标【教科书/临床指南/专家共识 年份 / 医学常识】 |
| 8 | 过错=因果 | 有告知瑕疵就定预后因果；有过错就「次要责任」而无 but-for / 实质性因素 |

病历矛盾三原则：他份材料足以印证则可采并说明理由；均无印证时对查明事实采对患者有利的理解（病历形成保管在医方）；医患记载都模糊则标明待质证，不擅自定伪。

## 重新鉴定（只评技术理由）

常见触发：分析说明空泛、依据与本案对不上、损害或原因力未论证、过错与因果未分开。重鉴后原因力**常上调**（次要→主要），初稿宁写清区间与反事实，不要为了「稳」而压低且不说理。资质/二元化争议不是本助手能裁定的事项。

## 对七章的对表（审本报告时）

| 章 | 额外看 |
|----|--------|
| integrity | 缺页、串页、麻醉/术式互斥是否写入第二章「病历合规性分析」；有无越权定篡改 |
| diagnosis / treatment / consent | 应然三源是否标出处；拟行≠已做 |
| damage | 非死亡固定句；死亡不用终末状态替代根本死因 |
| causation | （一）分医院写机制、不写百分比；（二）自身疾病因素与各医院整体医疗过错各一条百分比，等级与区间一致；多家医院各写一条，不合成「医方」 |

## 产出

`notes.md` 写：不合格项（对应上表编号）→ 建议（维持 / 改原因力档 / 补检查 / 建议重新鉴定）→ 不要改的点。用户点名改稿后，只对相关章再 `fill_report`（每章一次调用，可并行）。
