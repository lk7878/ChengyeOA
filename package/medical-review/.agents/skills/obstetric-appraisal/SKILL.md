# 产科鉴定（三时段，不套书内百分比）

已出现过本文件的 `<skill_content>` 后禁止再加载。不要再加载 `surgical-appraisal`、`emergency-appraisal`、`orthopedic-appraisal`、`fault-type-classification`、`causation-analysis`。过错与原因力用已加载的 `medical-fault-causation`；损害用 `damage-consequence`。本 skill **不改七章**，除非用户点名改稿。

过程写入 `reports/review/notes.md` 的「产科模板」节。催产素、胎心监护、筛查时点用波次 C 已有的 `expected_care_plan`，标【出处】；禁止为本 skill 再连打检索。未命中标【医学常识】。

## 三时段（五类共用）

1. **产前**：高危因素（糖尿病、感染、瘢痕子宫、B 超/NT/唐筛）、分娩方式评估与告知。  
2. **产时**：胎心/羊水、催产素指征与剂量、从窘迫识别到娩出的时差、助产或剖宫产决策、肩难产处理。  
3. **产后**：Apgar 与复苏、新生儿观察（感染、胆红素、血糖）。与产程无关的产后因素不要挂到产时过错上。

先拆时段再挂因果。自身疾病、脐带/胎盘因素、患方拒剖并签字可降档，不能单独免责。拟行未做的剖宫产不是已发生操作。死亡/死胎未尸检：死因确定性下降，仍须推定，声明低于尸检。

## 先定哪一类（只评一类）

| 类 | 何时用 | 先看什么 |
|----|--------|----------|
| 死胎 | 胎死宫内 | 高危是否告知；催产素有无指征；胎心骤降到娩出间隔；未尸检则标死因复杂 |
| 脑瘫 | 运动/姿势障碍、HIE 后遗 | 产前影像（出生后早期头颅 CT/MRI 脑白质异常倾向先天因素）；Apgar 与羊水；产时缺氧时长；产后管理是否独立致病 |
| 新生儿窒息 | 低 Apgar、复苏后死亡或重症 | 监护异常何时出现、何时被识别；终止妊娠间隔；催产素是否加重缺氧；复苏是否规范 |
| 肩难产臂丛 | 巨大儿/肩难产 + 上肢神经损 | 孕期血糖/估重/肩径胸径；分娩方式告知；肩难产时人员与手法（以当时规范为准）；头身娩出间隔记录 |
| 错误出生 | 产前筛查/超声漏诊后缺陷儿出生 | 果 = **错误出生本身**（丧失发现并知情选择的机会），不是畸形/伤残/死亡 |

对不上上表就停，回到方法库。主损害是脑瘫、交叉麻醉争议时仍走本 skill，麻醉句用方法库补，不加载 `surgical-appraisal`。

## 各类审查（只填本案有证据的项）

**死胎**：破膜后宫缩已好仍用催产素、剂量偏大、窘迫后决策过慢，易过过错门槛。母体/脐带/胎盘因素重则原因力从低，须 but-for，禁止抄「同等」。

**脑瘫**：出生后早期影像示先天发育不良，或出生 Apgar 良好且羊水清，产时过错与脑瘫的符合性弱，可无因果或极低档。产程决策反复、未持续监护、缺氧时间长，则产时过错可上调。产后肺炎/核黄疸等须单独问与产程有无机制联系。脑瘫诊断本身依据不足时先质疑诊断，再谈原因力。

**窒息**：核心是缺氧时间链。危急值（胎盘功能、监护异常）未识别算诊断延误。患方坚持阴道分娩并签字单独评价，不消灭观察与告知义务。死亡案先完成死因推定（已加载则勿再调 `autopsy-guidance`）。不用多器官功能衰竭顶替根本死因。

**臂丛**：肩难产本身难完全预见。过错多在评估、方式选择、告知和处理是否规范，不默认「助娩=完全原因」。为挽救生命先娩后肩等紧急措施可降档。伪造签字、多项核心过错叠加才能往高档，仍须本案论证。残留功能另评残。

**错误出生**：畸形是自身因素，与筛查过错无事实因果。查：是否按当时孕周完成该做的筛查/系统超声；可见异常是否漏看；设备/资质是否如实告知；局限性和下一步（如羊穿）是否告知。客观不能检出或本无诊断义务 → 过错可不成立。机会丧失**仍须**写六级+百分比（检出率/窗口不确定从低），不要用「只写机会丧失」空过第七章。
