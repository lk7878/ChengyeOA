# 手术鉴定（七步，不套书内百分比）

已出现过本文件的 `<skill_content>` 后禁止再加载。不要再加载 `obstetric-appraisal`、`emergency-appraisal`、`orthopedic-appraisal`、`fault-type-classification`、`causation-analysis`。过错与原因力用已加载的 `medical-fault-causation`；损害用 `damage-consequence`。本 skill **不改七章**，除非用户点名改稿。

过程写入 `reports/review/notes.md` 的「手术模板」节。术式规范用波次 C 已有的 `expected_care_plan`，标【出处】；禁止为本 skill 再连打检索。未命中标【医学常识】。

## 七步（六类共用）

术前检查 → 指征与方式/时机 → 并发症预案（无讨论记录不能认定已有预案）→ 知情告知（针对性，签字 ≠ 真告知）→ 术中操作与记录 → 术后观察 → 预后告知。

并发症 ≠ 免责。拟行 ≠ 已做。解剖困难、粘连、自身疾病可降档，不能单独免责。一过错一损害：告知瑕疵多挂「选择被改变」，操作/观察过错挂具体损伤。

## 先定哪一类（只评一类）

| 类 | 何时用 | 先看什么 |
|----|--------|----------|
| 甲状腺 | 声嘶、低钙、旁腺功能减退 | 术前喉镜/预案；术中探查喉返神经与旁腺、误切是否自体移植；术后声带/血钙；终身替代是否书面告知 |
| PCI | 支架术后出血、梗死、感染 | 抗栓与 INR 监测及超标处理；穿刺点与血红蛋白；感染是否培养+针对治疗；患方是否遵嘱复查 |
| 腹腔镜 | 胆漏、肠漏、输尿管/阴道瘘 | 能量器械与钛夹位置；损伤与术野时空符合；该中转未中转；术后引流/腹痛是否被镇痛掩盖 |
| 子宫切除 | 膀胱/输尿管阴道瘘，或争议在该不该切 | 粘连与术式；替代方案告知；瘘是缝合损伤还是热损伤（常术后数日出现）；流液后是否及时定性 |
| 脊柱 / 全麻拔管转运 | 拔管后窒息、植物状态、转运中骤停 | 困难气道是否评估；延迟拔管；转运是否有医护护送与监护；从发绀到有效气道的时差 |
| 椎管内麻醉 | 硬膜外/腰麻后呼吸循环崩溃 | 追加肌松是否必要；效果不佳如何处理；苏醒与转运是否达出室标准 |

对不上上表就停，回到方法库。主损害是拔管窒息、交叉产科时仍走本 skill；主损害是脑瘫则应走产科，不要两个专科连开。

## 各类审查（只填本案有证据的项）

**甲状腺**：切下标本未查旁腺、无保护记录、无预案，过错门槛易过。解剖困难可降档。暂时性（约 3 个月内恢复）与永久性分列损害。

**PCI**：基础心脏病常主导预后，监测/出血/感染过错多为促进因素，须 but-for，禁止抄「轻微」。INR 超标只减量不停药、血红蛋白骤降未纠，可上调。

**腹腔镜**：无粘连却胆总管横断等，操作符合性强。热损伤可迟发。告知不足单独一般不当然等于瘘的主因。异常体征用镇痛掩盖算观察过错。

**子宫切除**：子宫被切与瘘要分项。有指征而告知不全，原因力常偏低；操作+延误诊治挂瘘。广泛粘连是减责不是免责。

**拔管/转运/椎管内**：无医护护送转运、困难气道按常规拔管、追加肌松后无人监护，属基本规范偏离，原因力可高，仍须本案论证，禁止抄「完全」。环甲膜穿刺不能长期替代气管切开/插管。死亡案先完成死因推定（已加载则勿再调 `autopsy-guidance`）。
