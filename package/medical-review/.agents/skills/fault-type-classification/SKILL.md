# 过错子类型（只补分类，不另给百分比）

已出现过本文件的 `<skill_content>` 后禁止再加载。不要再加载 `causation-analysis`、`opinion-writing`。八类主类型、六级+百分比、第七章句式以已加载的 `medical-fault-causation` 为准。本 skill **不改七章**，除非用户点名改稿。

过程写入 `reports/review/notes.md` 的「过错分型」节。细则用波次 C 已有的 `weknora_method`，不要为本 skill 再连打检索。

择一**主类型**，可并列次类型。有过错无对应损害 → 过错可写、原因力为无。并发症 ≠ 过错。拟行 ≠ 已做。

## 八类 → 子类型（先定性再挂因果）

| 主类型 | 子类型（择一） | 认定时盯住 |
|--------|----------------|------------|
| 诊断 | 错误诊断（甲当乙/有当无）；延误；漏诊并存或新发；病因判错；性质/程度判错 | 当时资料是否足以作出或修正；延误**不以时长唯一标准** |
| 用药 | 药理性质相反；品种选择错；途径/剂量/配伍/疗程错；ADR 处置不当 | 适应证、禁忌、说明书/指南、个体因素（肝肾/过敏/妊娠）；合格药常规用量下的 ADR 本身不是过错，未观察未停未救才是 |
| 手术/操作 | 无指征而做；有指征但方式不当；时机过早/过迟；术中操作偏离；围术期观察处理不当 | 偏离须参与损害机制；「不排除操作错误」不是主要原因的同义词 |
| 过度医疗 | 过度检查；过度治疗；过度护理 | 无适应证或无增量获益，并造成可避免伤害或费用/风险；常规必要检查不是过度 |
| 知情告知 | 病情；措施/替代方案；风险；死亡后尸检建议；告知对象错误 | 签字 ≠ 真告知（格式同意书不够）；告知瑕疵须与**选择被改变**有关联才进原因力，单独一般不当然等于诊疗主因 |
| 机会丧失 | 丧失生存/康复机会；错误出生/错误受孕 | 窗口可实施 + 无正当禁忌 + 未评估/未实施/未告知替代，三者同时成立。**仍须写六级+百分比**（窗口短或获益不确定从低），不要用「只写机会丧失」空过第七章 |
| 病历书写 | 不客观；不真实；不准确（粘贴/互斥）；不及时；不完整；不规范 | 仅当影响查明事实、连续性或患方权益时单列；纯形式瑕疵不入意见。记录矛盾按三原则取舍，**不替法官定伪造/篡改** |
| 其他 | 转诊/会诊；观察与抢救组织；院感；护理；非卫技人员上岗 | 能归入前七类就不要用兜底 |

错误出生的果是错误出生本身，不是新生儿伤残。死亡后未建议尸检：写技术后果（死因确定性下降），不改写成赔偿比例。

## 归因（只影响档位方向）

- 医方：该查未查、该鉴别未鉴别、知识/操作偏离当时规范 → 过错门槛易过。  
- 患方：隐瞒病史、拒查拒治、自行出院 → 单独评价，不得全算医方。  
- 客观：症状极不典型、窗口极短、当时当地条件 → 可降档，不能单独免责。

## 产出与红线

`notes.md`：主类型 + 子类型 → 当时应然【出处】→ 实然（页码）→ 对应哪一损害 → 原因力仍按 `medical-fault-causation` 本案论证。  
禁止写入书内案件统计、「典型原因力」或 C2/C3 编号当本案数字。不要出鉴定咨询意见书。
