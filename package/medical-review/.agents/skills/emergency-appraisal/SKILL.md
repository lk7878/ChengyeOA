# 急危重症鉴定（三要素，不套书内百分比）

已出现过本文件的 `<skill_content>` 后禁止再加载。不要再加载 `surgical-appraisal`、`obstetric-appraisal`、`orthopedic-appraisal`、`fault-type-classification`、`causation-analysis`。过错与原因力用已加载的 `medical-fault-causation`；损害用 `damage-consequence`。本 skill **不改七章**，除非用户点名改稿。

过程写入 `reports/review/notes.md` 的「急危模板」节。规范与时间窗用波次 C 已有的 `expected_care_plan`，标【出处】；禁止为本 skill 再连打检索。未命中标【医学常识】。

## 三要素（五类共用）

1. **诊断窗口**：首诊到关键检查/确诊的时差；是否测生命体征、纳入鉴别、按当时指南完成 CT/CTA/心电图等。窗口被错过 → 考虑机会丧失，仍须写六级+百分比。  
2. **病程速度**：从症状到终点（破裂、休克、大面积梗死、猝死）有多短。进展快可**降低**原因力，不能单独免责。  
3. **机会丧失**：及时规范救治的获益是否可识别。获益不确定或不作为型过错，原因力从低；禁止「反正也会死」直接写无因果。

疾病凶险只做减法，不做免责。医院等级不能消灭基本查体、生命体征和鉴别诊断。拟行未做的手术不是已发生损害。

## 先定哪一类（只评一类）

| 类 | 何时用 | 先看什么 |
|----|--------|----------|
| 主动脉瘤/夹层 | 撕裂样胸背痛、上下肢血压差、影像提示夹层/瘤、术后引流或血红蛋白进行性下降 | 首诊生命体征；夹层是否纳入鉴别；临床诊断与 CTA/超声是否一致，不一致有无会诊；术后血压/血红蛋白/引流量 |
| 急腹症 | 外伤或炎症/梗阻急腹、ERCP 后腹痛、休克 | 休克时是否先复苏/剖腹止血而非先转院做 CT；操作损伤与解剖是否符合；原发伤致命性 |
| 脑卒中溶栓 | 突发偏瘫/失语，争议在溶栓或取栓窗口 | 发病到就诊、到影像、到决策的时点；禁忌是否排除；溶栓后 NIHSS/血压监测；错失窗口单列「机会丧失」，残留功能另评残 |
| 心肌炎 | 消化道或发热起病后迅速循环衰竭、死亡 | 是否仅就诊一次、症状是否极不典型；有无心电图/肌钙蛋白/留观记录；转院途中有无监护 |
| 病理诊断 | 外院病理、术中冰冻、术后大标本与术中所见不符，或据此扩大切除/化疗 | 是否复阅外院切片；冰冻是否本可避免；术前错与术后错**分项**定果 |

对不上上表就停，回到方法库，不要硬套。

## 各类审查（只填本案有证据的项）

**夹层**：无生命体征或未鉴别 → 过错门槛易过；影像与临床矛盾未讨论 → 指征风险大；术后活动性出血未识别 → 另列观察过错。死亡率高只能降档，不能写成无因果。

**急腹症**：开放性腹伤+失血性休克的应然是止血优先（以 `expected_care_plan` 已核实规范为准）。延误可构成生存机会减少；原发伤极重时原因力常偏低，仍须 but-for，禁止抄「轻微」。ERCP 等操作损伤看时间与解剖符合性，病情复杂可降档但不是无过错。

**溶栓**：时间窗以**当时**指南为准（检索，不默背旧数字）。应评未评、应溶未溶且无正当禁忌 → 机会丧失成立，原因力从低到中，除非窗口内且获益较明确。违反禁忌强溶另评出血损害。告知未提溶栓/取栓，单独一般不等于诊疗主因。

**心肌炎**：「症状极不典型 + 仅一次短诊 + 当时资料不足以想到」可以倾向无因果或极低档；留观无观察、心电图异常未处理、转院无监护则另算。死亡案先完成死因推定（已加载则勿再调 `autopsy-guidance`）。

**病理**：不可盲信外院报告。术前病理错 → 错误/扩大切除；术后大标本仍错 → 错误化疗等，**一过错一损害一原因力**。须告知冰冻/穿刺的局限性。冰冻决策本身是否必要先问。
