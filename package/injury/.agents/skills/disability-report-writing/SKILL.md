# 鉴定咨询意见书

已出现本文件的 `<skill_content>` 后禁止再加载。不要调用 `fill_review_report` 或 `fill_period_report`。文书名称只用「鉴定咨询意见书」。它不是司法鉴定意见书。

## 步骤

1. 材料在本轮附件或 `materials/`。先回复「正在阅读病历」，再 `parse_records`（不要填 `max_pages`）。禁止 `job_output` 空等，禁止整本 `convert_file` OCR，禁止读 `pages/`。完成后读 catalog、timeline、meta，再用 `parse_records_query` 抽病案首页、入院记录、手术记录、出院记录、影像报告。可复制文本的 PDF 才 `convert_file`。
2. 只定一部主标准。用户或委托材料写明的优先。否则：工伤、劳动能力、职业病用《劳动能力鉴定 职工工伤与职业病致残等级》（GB/T 16180-2014）；人身保险、意外险用《人身保险伤残评定及代码》（GB/T 44893—2024）；民事人身损害用《人体损伤致残程度分级》。看不出来就 `ask_user` 一次：「按民事赔偿、工伤，还是人身保险？」问完之前不要出件。不要默认连评多部。
3. 病历看不出外界致伤、记载为自身疾病时，结论写「不符合评残前提，不评定伤残等级」，只引用已选定那一部标准的总则。不要写因果关系参与度，不要再按另一部标准给等级。
4. 同一轮 `weknora_search`。查条款时 query 写「标准全称 + 条款号或部位」。两处以上再查该标准的「多处伤残」。条款号必须来自命中原文。未命中写「条款未能核实」，不得定级。
5. 调用一次 `fill_report`。十一个字段都传。身份、委托单位未知填「（待补充）」。标准未定、伤在哪里不清楚时，先问，不要出件。生成后 `present` 工具返回的 docx，不要假设固定文件名。
6. 用户只补充委托单位、身份证或改一句时，未改字段填「（沿用）」。只改身份信息时不要改等级。

## 六章怎么写

病历记载按原文采信。不质疑检查和病历真伪，不写医疗过错，不编造事故经过和委托事项。委托事项就是伤残等级咨询。

- `standard`：一部标准的全称。GB/T 44893—2024 写《人身保险伤残评定及代码》。
- `public_opinion` 先写确定结论，再列分项。用：`被鉴定人损伤对照《标准名》，构成×级伤残。` 或：`不符合评残前提，不评定伤残等级。` 禁止「若适用」「四级或七级」「建议评定为四级；建议评定为七级」。
- 分析说明里每条末尾【出处：《标准名》条款号】。多处伤残只按本次命中的该标准规则就高或晋级，最后仍只出一个等级。

轻伤、重伤用《人体损伤程度鉴定标准》，只在对话里回答，不得写进本意见的等级。

受伤已满 3 个月的，直接评定。未取内固定、未满 6 个月，不因此拒评；需要提示时在 `analysis_explanation` 末尾加一句，不改变等级。未满 3 个月的，仍按现有材料给出一个参考等级，并写明「距受伤未满 3 个月，等级供参考」。

对话只报：这是咨询意见、适用标准、最终等级、待补充项、Word 路径。不要把六章再贴一遍。
