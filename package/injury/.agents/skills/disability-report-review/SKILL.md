# 伤残鉴定报告审核

已出现本文件的 `<skill_content>` 后禁止再加载。不要调用 `fill_report` 或 `fill_period_report`。

## 审查要求

1.只对报告的鉴定结论和分析讨论的合理性进行审查；条款是否成立仍决定总判。
2.所有鉴定的过程、原始材料、临床检验陈述的结果不要去质疑，我们客观推定被鉴定人的客观病历和法医师的临床检查发现都是真实且正确的；
3.鉴定报告的审核结论一定要简洁，不需要输出太多描述性内容，我们主要关心鉴定报告结论的合理性。
4.另查低级书写错误，以及不改变条款判断的其他不合理之处。二者只写入潜在风险提示，不写入审核结论，不因此改总判。

书写错误：错别字，姓名、左右侧或部位前后不一致，文号或数字明显抄错，受伤、住院、手术、鉴定日期互相矛盾，分析讨论与鉴定意见中的日期或等级数字抄写不一致。每条一句，点出矛盾的两处原文。此类写完后必须另起一句：「可能为识别问题，请人工进行校对」。没有书写错误时不要写这句。

其他不合理之处：分析讨论与鉴定意见的等级或条款互相矛盾、同一事实前后说法不一致、晋级或就高的计算说不通，但按本次检索到的条款仍不能直接改判的。各写一句，放在潜在风险提示。不加上述 OCR 备注。病历和临床检查仍不质疑。

注：检查鉴定时限是否满足评价标准中鉴定时限的要求，例如，评价标准要求受伤需满 3 个月才可以鉴定。鉴定时限符合要求、且没有书写错误或其他不合理之处时，潜在风险填「无。」，不要把「已满 3 个月」再写一遍。时限不足、内固定未取出、书写错误、其他不合理之处都只作为潜在风险，不影响审核结论。

## 多份意见书

一份鉴定意见书对应一份审核意见。唯一键是被鉴定人姓名加鉴定机构加文号，不是姓名。

同一人在多家机构各有意见书时，不默认全审。用户指定了附件、路径、机构或文号，只审这一份。工作区里多于一份、又没说审哪一份，先 `ask_user` 列出机构和文号，不要挑最新的一份，也不要把几家结论写进同一份 Word。用户明确说「都审」时，逐份各调用一次 `fill_review_report`，一份完成后再审下一份，不要并行。

`subject_name` 只写姓名。`report_ref` 写「机构，文号」，文号照录。机构不要写进姓名。换了文号就是新的一份，字段全部重写，禁止「（沿用）」。只改同一文号上一份审核意见的一句时，未改字段才填「（沿用）」。

## 步骤

1. 先列出本轮附件和 `materials/` 里的每一份鉴定意见书：文件路径、被鉴定人、机构、文号。按上一节确定审哪一份。先回复「正在阅读鉴定意见」，只读这一份。可复制文本用 `convert_file` 指定该文件。扫描件用 `parse_records`；目录里有多份时，随后 `parse_records_query` 的 `file` 必须是这一份的文件名，禁止引用其他文件里的鉴定意见。只抽取：委托事项与适用标准、分析说明或分析讨论、鉴定意见、各伤残条款与等级、受伤日期与鉴定日期。
2. 病历、影像、手术和法医临床检查一律按报告陈述采信。不复核手法，不质疑材料真伪，不评价鉴定程序和资质。
3. 对每一条伤残，同一轮用 `weknora_search` 检索报告所引编号对应的那一部标准。query 写「标准全称或标准编号 + 条款号」。两处以上再检索该标准的「多处伤残」。未命中写「条款未能核实」，不得编造条款号，也不得据此判不合理。
4. 只判断：在报告已陈述的伤情下，所引条款和等级是否成立；多处伤残的就高、晋级是否符合该标准本次检索到的原文。不得套用另一部标准的晋级规则。
5. 报告所写标准名称和编号对不上时，适用标准栏照录报告原文，并在审核结论或条款对照写明正确名称。GB/T 44893—2024 的名称是《人身保险伤残评定及代码》是《人身保险伤残评定标准》。名称问题不单独把总判写成「结论不合理」；等级仍按该编号对应的标准审核。
6. 通读委托事项、分析讨论和鉴定意见，不复述。标出错别字、日期矛盾和其他低级书写错误，以及不改总判的其他不合理之处，只记入 `risk_notes`。
7. 一份意见书调用一次 `fill_review_report`，再 `present` 返回的 docx。`subject_name` 只写姓名，`report_ref` 写机构和文号。文件名会带上文号，不要自己把机构塞进姓名。只改同一文号的一句时，未改字段填「（沿用）」。

## 怎么写

总判只用三档之一，放在 `review_verdict` 开头：`结论合理`、`部分条款需调整`、`结论不合理`。后面最多一句原因。名称与编号不一致时，这句原因里要写出正确名称。

`item_review` 每条伤残一段，格式固定：

`原意见：×级（条款号，条目要点）。审核：维持。`

或

`原意见：×级（条款号，条目要点）。审核：应调整为×级。理由：一句。【出处：《标准名》条款】`

`original_conclusion` 只摘鉴定意见中的结论句。`risk_notes` 无事项时填「无。」。有事项时按此顺序，各一句：时限不足或内固定未取出（如有），句末「不影响审核结论」；其他不合理之处（如有）；书写错误（如有），并紧跟「可能为OCR识别问题，请人工进行审查」。书写错误和其他不合理之处不要写入 `review_verdict` 或 `item_review`。

禁止复述病史、手术经过、检查数值和鉴定过程。禁止 Markdown 表格和 `#` 标题。对话回复只报总判、需调整的条款（如有）和 Word 路径。
