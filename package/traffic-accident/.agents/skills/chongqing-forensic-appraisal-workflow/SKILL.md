# 重庆交通事故鉴定执业流程

本技能不读取 `references/`。只用于重庆。条例与 2020 年指南冲突时，以《重庆市司法鉴定条例》命中原文为准，并写明指南的对应差异。未命中写「条款未能核实」。

## 检索

下结论前调用 `weknora_search`。query 写法规或文件全称加事项。同一轮最多 4 次。

- 「重庆市司法鉴定条例 施行」
- 「重庆市司法鉴定条例 受理」
- 「重庆市司法鉴定条例 中止」或「检材」「重新鉴定」
- 「重庆市司法鉴定执业活动流程指南」加同一事项
- 需要表单时：「重庆市司法鉴定执业活动流程指南 附件」加表单用途

只保留标题含所选法规或文件的命中。受理工作日、施行日期以条例命中为准，不把指南里的旧时限直接用于条例施行之后的案件。收费金额、浮动比例没有出现在命中原文里就留空。引用写成【出处：《文件名》条款号】。

## 审查

1. 确认案件是否适用重庆、程序发生时间和诉讼阶段。
2. 审查机构及人员资格、委托人对材料的确认、利益冲突和既往参与。复杂、疑难、特殊事项是否需要相关专业高级职称，以命中原文为准。
3. 可能损耗或损坏检材、原物的，检索是否必须取得委托人书面同意并记录原状态。缺材料或暂时不能开展时，把中止和终止分开。中止、恢复是否要书面通知，以命中原文为准。
4. 原委托的补充、事项变更、重新鉴定、形式补正分开审查。鉴定人安排和签名规则以命中原文为准，并记下与 2020 指南不一致的地方。
5. 表单底稿按附件命中的用途改编，核对复核、签发、发送、签收、出庭和归档。指南附件里没有的中止、恢复等文书，标明不是原附件。

## 输出

写明节点、依据、待补材料和文书草稿，以及旧模板需要改的地方。不自动通知、收费或投诉。不签发意见。不把重庆规则写成其他地区的规则。
