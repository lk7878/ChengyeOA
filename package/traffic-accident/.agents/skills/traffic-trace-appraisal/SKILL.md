# 道路交通事故痕迹物证鉴定

本技能不读取 `references/`。受理、保全、检验和文书的通用要求只来自 `weknora_search` 命中的 SF/T 0072—2020《道路交通事故痕迹物证鉴定通用规范》。未命中写「条款未能核实」。这部规范不提供接触认定、车速或信号灯的具体阈值。

## 检索

下结论前调用 `weknora_search`。query 写「道路交通事故痕迹物证鉴定通用规范」加事项。同一轮最多 4 次。

## 流程

1. 把「痕迹鉴定」拆成可证明的事项：对象、事发阶段、要的是接触、种属、分离还是过程。材料审查和正式受理分开。核对人、车、物的身份、来源、状态和事后改变。
2. 建立带位置、方向和比例尺的证据目录。现场图、照片、车体痕迹、衣着损伤、散落物和视频要能互相对上。缺项和矛盾先列出。
3. 易灭失的先固定，无损的先做。观察结果、对应特征、形成机理和事故叙述分开。先处理接触和状态，再讨论过程。
4. 按下面的表只加载一个专项。速度、车辆性能、设施改走对应技能。没有专项依据时列补材，不用本规范的标题填具体数值。

| 争点 | 技能 | 知识库中的标准 |
|------|------|----------------|
| 现场勘查和提取 | `accident-scene-trace-survey` | GA/T 41—2019 |
| 接触、同一和分离 | `collision-trace-comparison` | GA/T 1087—2021 |
| 由图像重建位置或过程 | `image-accident-reconstruction` | SF/T 0160—2023 |

| 信号灯状态 | `traffic-signal-state-appraisal` | SF/T 0073—2020 |

## 输出

逐项写结论、依据、时点和限制。文件协助不写成已经完成的现场检验，不伪造签名。不写责任比例。
