# 视频交通信号灯状态鉴定

本技能不读取 `references/`。对象、参考灯、配时和时间同步的要求只来自 `weknora_search` 命中的 SF/T 0073—2020《基于视频图像的道路交通事故信号灯状态鉴定规范》。未命中写「条款未能核实」。这部标准常先返回页面图片，图片不能当条款。口述「当时是红灯」不能代替图像鉴定。

## 检索

下结论前调用 `weknora_search`。query 写「基于视频图像的道路交通事故信号灯状态鉴定规范」加事项。同一轮最多 4 次。

- 「基于视频图像的道路交通事故信号灯状态鉴定规范 目标信号灯」
- 「基于视频图像的道路交通事故信号灯状态鉴定规范 参考信号灯」
- 「基于视频图像的道路交通事故信号灯状态鉴定规范 时间」或「配时」

只保留标题含 SF/T 0073 或该书全称的可读中文。第一次只有图片或英文摘要时，用条款号再查一次。引用写成【出处：《基于视频图像的道路交通事故信号灯状态鉴定规范》条款号】。

## 审查

1. 固定所问的对象、车道或行人方向、起始位置，以及对应的那一组灯。碰撞时刻和到达、通过该位置的时刻分开。
2. 检查原始视频和时钟。逐帧标出目标、参照位置、目标灯和参考灯的变化。多台摄像机用同一现场事件对齐时间，并写误差。不默认画面上的叠加时间已经同步。
3. 配时以事发时的控制方式为依据，核对日计划、感应、自适应、人工优先或故障。事后到现场看若干周期，只证明观察当时的条件。转用于事发时，要有证据。
4. 目标灯看不见时，先证明参考灯和目标灯的相位关系，以及该配时能否用于事发时。其他方向是绿灯，或有人、有车通过，不能单独证明本方向的灯色。
5. 通过停止线或参照位置的时刻如果要回推，保留时间和距离的误差。范围跨过灯色切换时，写可能的状态和不能确认的点。单帧没有颜色时，先按命中原文检查闪烁、采样、曝光和遮挡，不直接写成熄灭或某一种灯色。

## 输出

写明对象、方向、位置、时刻、目标灯状态和依据。附关键原始帧。条件不足就写不能确认。不写成闯红灯或责任认定。
