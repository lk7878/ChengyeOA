# 事故工业车辆类型识别

本技能不读取 `references/`。分类定义只来自 `weknora_search` 命中的 GB/T 6104.1—2018《工业车辆 术语和分类 第1部分：工业车辆类型》。未命中写「条款未能核实」。知识库没有 2025 版。需要现行定义时列为缺项，不把 2018 的条号改成新的年份继续引用。

## 检索

下结论前调用 `weknora_search`。query 写「工业车辆 术语和分类 第1部分」加类型或「范围」。同一轮最多 4 次。

- 「工业车辆 术语和分类 第1部分 范围」
- 「工业车辆 术语和分类 第1部分 叉车」或「牵引车」等候选类型

只保留标题含 GB/T 6104.1 或该书全称的可读中文。页面图片和英文摘要丢弃。第一次只有图片时，用类型名称再查一次。引用写成【出处：《工业车辆 术语和分类 第1部分：工业车辆类型》条款号】。

## 审查

1. 先写本案日期、目的和准备引用的版本。
2. 用范围条款判断是不是工业车辆。记录标识、设计用途、轮式或轨道、驱动和操作方式。留出不属于该范围的可能。
3. 按命中的分类维度核对作业、动力、控制、起升和运行方式，再比对具体类型的定义。铭牌、说明书和实物、事故时结构、改装，分开记录。不凭产品名或一张照片定型。
4. 关键结构因损坏看不清时，不强行确定细类。

道路上的机动车类型改加载 `vehicle-type-identification`。安全性能另选检测标准。工业车辆类型不能推出特种设备目录、道路法律属性、准驾资格、额定载荷或事故责任。

## 输出

写明候选类型、定义要件、证据、匹配和差异、未知结构、还要补查什么，以及库中没有后续版本这一限制。
