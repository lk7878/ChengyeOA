# 交通事故司法鉴定全国程序

本技能不读取 `references/`。程序要求只来自 `weknora_search` 命中的《司法鉴定程序通则》（2016）。未命中写「条款未能核实」。这不是全部诉讼规则。重庆案件的受理时限改检索《重庆市司法鉴定条例》，不要把两部的工作日混用。

## 检索

下结论前调用 `weknora_search`。query 写「司法鉴定程序通则」加事项。同一轮最多 4 次。

- 「司法鉴定程序通则 委托受理」
- 「司法鉴定程序通则 回避」
- 「司法鉴定程序通则 鉴定材料」或「现场提取」
- 「司法鉴定程序通则 鉴定时限」或「补充鉴定」「重新鉴定」「终止」
- 「司法鉴定程序通则 鉴定意见书」或「出庭」

只保留标题含《司法鉴定程序通则》的命中。引用写成【出处：《司法鉴定程序通则》条款号】。受理工作日以命中原文为准，不在本技能里预写天数。

## 审查

1. 记录委托人、诉讼阶段、地区、机构及人员资格、事项、既往鉴定和材料是否可用。正式受理和咨询分开。
2. 收案、材料、受理或不受理、协议、指派和回避，按命中的相应条款核对。
3. 材料流转、适用标准、现场提取的人数和见证、实时记录，按命中条款核对。提出检验计划不等于已经获得提取或破坏原物的授权。
4. 期限、终止、补充材料、补充鉴定、重新鉴定、咨询和复核，先确定行为性质，再选程序路径。改标题不能代替合法办理。
5. 文书签章、意见分歧、送达、解释、补正、档案和出庭，按命中条款核对。实质变更不能写成补正。

## 输出

按事项列出事实依据、对应条款、已经满足、未见记录或待核验、影响和下一步。只在记录足以对照条款时才写某项程序未见履行。程序瑕疵不直接写成鉴定意见无效。是否受理、是否签发，交给机构。
