# 事故过程分析与仿真验证

本技能不读取 `references/`。流程、参数和验证要求只来自 `weknora_search` 命中的 DB50/T 1655—2024《道路交通事故过程分析及重建技术规范》。未命中写「条款未能核实」。先检索适用范围。委托或事发地不在该范围内时，写明不适用，不默然套用。

## 检索

下结论前调用 `weknora_search`。query 写标准全称加事项。同一轮最多 4 次。

- 「道路交通事故过程分析及重建技术规范 范围」
- 「道路交通事故过程分析及重建技术规范 参数」或「验证」
- 「道路交通事故过程分析及重建技术规范 碰撞」
- 只有涉及轿车名义载荷分布时：「轿车质量分布」

只保留标题含所选标准的命中。引用写成【出处：《标准名》条款号】。程序问题另检索 SF/T 0072—2020。

## 审查

每个几何、质量、质心、轮胎与路面、人体与约束、运动和碰撞参数，标明来源是实测、原始资料、文献、拟合还是未知。事故时的载荷优先用事实。GB/T 5910 的名义乘员质量只在命中原文允许的轿车参考范围内使用，不代替真实体重，也不推广到其他车型。

先核对碰撞及碰撞后的位置、接触部位和变形，再约束碰撞前的参与方。标准对碰撞前某时段的定义，以命中原文为准；没有材料时，不按该定义编造轨迹。

模型写明软件版本、所选方程、坐标、单位、初始条件和限制。迭代保留尝试范围、误差指标和不止一个可行解。优先用碰撞参数、轨迹和损伤验证。画面逼真或只对上一个停止位置，不能确认整个过程。调过的参数和用来验证的独立证据尽量分开。没有独立证据时，写明这是拟合。

命中原文没有统一的合格百分比时，不自设一个。模型文件、运行配置、关键结果和截图一起保存。动画标明是重建或假设，不是原始录像。
