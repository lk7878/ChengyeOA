# 交通事故鉴定通用入口

先确认本轮已经加载 `traffic-appraisal-plan`。技术专项以那张表为准，本技能不另选主标准，也不再列第二份路由。

## 本技能只做这几件事

1. 分清用户要的是受理审查、检验方案、技术分析、文书底稿，还是复核已有意见。写明地区、诉讼阶段、对象、委托事项和材料缺口。事项含混时先问。文书底稿改加载 `traffic-report-writing`，已有意见书改加载 `traffic-report-review`。
2. 全国程序需要时加载 `forensic-appraisal-procedure`。重庆案件再加载 `chongqing-forensic-appraisal-workflow`。程序技能不代替技术主标准，时限以各自检索到的原文为准。
3. 证据编号、原件状态、检验时状态、事故时状态和技术假设分开。先做不改变检材的审阅，再写需要机构实施的检验计划。
4. 每一问按「材料 → 方法 → 结果 → 推论 → 限制」写。技术关联不是法律责任。不写责任比例，不写意见必然被采信或当然无效。

底稿列出待核实、待检验、待签发。不虚构已经完成的检验和签名。规范里的通知、收费不授权助手对外办理。
