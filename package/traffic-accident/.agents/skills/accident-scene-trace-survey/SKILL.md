# 现场痕迹物证勘查与保全

本技能不读取 `references/`。发现、定位、固定、提取和保全的要求只来自 `weknora_search` 命中的 GA/T 41—2019《道路交通事故现场痕迹物证勘查》。未命中写「条款未能核实」。程序问题另检索 SF/T 0072—2020，不把勘查规范写成同一认定结论。

## 检索

下结论前调用 `weknora_search`。query 写「道路交通事故现场痕迹物证勘查」加对象。同一轮最多 4 次。

- 「道路交通事故现场痕迹物证勘查 车辆痕迹」

## 方案

按易灭失程度和事故类型安排顺序，并分层记录：道路和参照系，车辆或人员终了位置，轮迹和挫划，散落和遗洒，车体与人体的对应，视频和电子数据。现场原状和救援后的移动分开写。

轮迹写种类、起止、突变、方向、宽度、分段和弧线。不是所有深色印迹都是制动印。散落物写分布和后来的移动，不直接用聚集中心当碰撞点。车体写身份、部位、三维尺寸、上下缘高度和物质交换。人体先衣着、后体表，并与法医资料衔接。

固定要能从整体位置找到局部，再看到细节。编号、方向、比例尺和参照一致。新痕迹或遮挡先固定，再按计划处理。粉笔、胶带和试剂不要污染待检表面。可能互相对应的双方、比对样本和空白对照分别提取。断口不反复强行拼接。

只有案卷照片时，列出照片上看不到、需要补勘的内容。所见和推论分开。允许误差不是已经达到的测量精度。

## 输出

写明勘查对象、固定和提取方法、不能检查的内容、保全和交接。不写责任，也不把未检见写成未接触。
