# 接触碰撞痕迹比对

本技能不读取 `references/`。认定、否定和不确定的条件只来自 `weknora_search` 命中的 GA/T 1087—2021《道路交通事故痕迹鉴定》。未命中写「条款未能核实」。程序要求另检索 SF/T 0072—2020。

## 检索

下结论前调用 `weknora_search`。query 写「道路交通事故痕迹鉴定」加事项。同一轮最多 4 次。

- 「道路交通事故痕迹鉴定 同一认定」
- 「道路交通事故痕迹鉴定 种属」或「整体分离」
- 「道路交通事故痕迹鉴定 碰撞接触」
- 「道路交通事故痕迹鉴定 意见」

只保留标题含 GA/T 1087 或《道路交通事故痕迹鉴定》的命中。不要把 SF/T 0072 的程序条款当成比对结论。引用写成【出处：《道路交通事故痕迹鉴定》条款号】。

## 比对

1. 先定要证明的是特定客体接触、某一类形成方式、同一整体分离，还是碰撞时的位置和过程。核对双方原件，以及旧痕、维修、拖移和提取历史。
2. 每一对痕迹先单独检验：位置、形态、材质、尺寸和高度、方向、层次、覆盖、新旧、附着和特异特征。再在有依据的姿态下看空间是否对应。
3. 符合点和差异点分开列，写特异性和能否解释。高度差要考虑载荷、制动点头、侧倾、变形和人体姿态。不为了消除差异随意设定姿态。
4. 物质相似、同一种轮胎花纹或同色，只支持到该层次。成分、DNA、轮胎或号码需要别的方法时，列为专项，不在这里下结论。整体分离要保护边缘，记录互补轮廓和层次，不强行拼合。
5. 把痕迹组、相对运动和现场位置放在一起，检查其他接触、二次碰撞和二次转移。模拟只检验机理是否可能，动画不能证明同一。
6. 认定、否定、不确定的用词和条件以命中原文为准。未检见、不能认定、可以排除，不能互相替换。

## 输出

给出可复核的特征对照、差异解释、形成机理、不能排除的其他来源和结论边界。发生接触不等于车速、过错或全部事故过程已经确定。
