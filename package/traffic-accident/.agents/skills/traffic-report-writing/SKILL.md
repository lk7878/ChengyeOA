# 交通事故鉴定咨询意见

已出现本文件的 `<skill_content>` 后禁止再加载。文书名称只用「交通事故鉴定咨询意见」。不要写成司法鉴定意见书，不要写「本鉴定意见如下」，也不替代公安机关的事故责任认定。

范例是司法鉴定科学研究院 2022—2025 年能力验证项目参考答案，共 13 份。用途是结构和论证，不能视为国家或行业标准、评分通则或本案事实。范例中的数值、路名、人物、VIN、哈希、工具版本、旧标准条文和结论不得抄入本案。来源索引里已核对的原页疑点不得继承。

## 先读什么

主标准和那个专项已经按 `traffic-appraisal-plan` 选定并加载。本技能不另选主标准。条款只引用 `weknora_search` 命中的可读中文，标注【出处：《标准名》条款号】。页面图片、英文摘要和乱码不写入。范例引用的旧版方法不自动成为本案依据。

每次先读 [报告结构和证据组织](references/report-structure.md)。再只读与本案事项对应的一篇，不要通读 13 份全文：

- 力学或视频车速：[车速报告](references/speed-writing.md)。
- EDR 车速：[EDR报告](references/edr-writing.md)。
- 接触碰撞与痕迹：[痕迹报告](references/trace-writing.md)。
- 驾乘、骑推行为：[行为方式报告](references/behavior-writing.md)。
- 指定时点灯色：[信号灯报告](references/signal-writing.md)。
- 完稿前用 [质量复核清单](references/review-checklist.md)。要核对某一例的页码或疑点时，才读 [来源索引](references/source-index.md)，并按需打开 `references/source-text/` 里对应的那一份。原页以 `references/sources/` 下的 PDF 为准。不要打开来源清单里 `E:\医学教科书` 的路径。

道路设施、车辆安全性能、火灾、现场勘查、图像重建和仿真没有专题范文。这些事项只用通用结构，技术内容仍以已加载专项和检索原文为准。

## 步骤

1. 还没选定主标准，或材料不足以支持该委托事项时，先 `ask_user`，不要写文件。
2. 同一轮按主标准补齐 `weknora_search`。query 写标准全称加本案争点。配套标准最多再查 2 次。
3. 起草、改写或自查都按上面那一篇组织证据链。能力验证的短答题格式和字数限制不是正式文书格式。改写时保留已验证事实、计算精度、结论范围和不确定性；需要实质改结论时单独写理由。
4. 每个结论按「材料编号 → 检验或测量 → 参数和方法 → 分析 → 适用边界」写。区分委托方陈述、照片所示、实物检验、记录字段和推断。没有亲自实施的检验写「所提供照片显示」「记录载明」或「拟检验」，不假称已现场检验。
5. 速度只代入材料中的原始数据和命中公式。区间平均、帧间隔或匀减速初速度用 `E:/A/package/traffic-accident/.agents/skills/scripts/calculate_speed.py`，不心算。公式未在检索片段中出现时，不计算。不能把平均速度或采样速度改称碰撞瞬间速度，不能把「不能认定」写成「可以排除」。
6. 用 `write` 写入 `reports/交通事故鉴定咨询意见.md`。需要附图时，图片单独成段，不要写进句子或表格单元格。图题写在图片标记的方括号里，路径相对案件目录：

   `![图1 左前翼子板擦痕（检材3）](materials/现场照片.jpg)`

   一段只放一张图。图题不要在下一行再写一遍。用户要 Word 时调用 `export_md_to_word`，`input` 填这份 md 的路径。不要用 `convert_file` 转这份咨询意见。导出后图片是居中的嵌入式图片，图题紧跟在图下。用户要打印稿或 HTML 时，复制本技能目录的 `report_render.html` 到 `reports/`，只替换 `{{ }}`。抬头保持「百佑智业 / 交通事故鉴定咨询意见」。图片放进 `<figure>`，用 `<img>` 换掉占位框；不要写死高度，不要 `object-fit: cover`。两张对照图各自写图题。没用到的检验分项删掉，不要留成“经检验未见异常”。
7. 然后 `present`。身份、检材来源未知写「（待补充）」。对话只说明：这是咨询意见、主标准、结论句、未能核实的点、文件路径。不要把全文再贴一遍。

## 章节

正文用连贯段落，不用表格，不编造案号、委托日期和检测数值。

1. 委托事项。只写一件事，并写明主标准全称和编号。
2. 检材。逐项列出材料中实际有的现场图、视频、记录仪或 EDR 数据、车辆检验记录、痕迹照片。没有的不要写成「经检验」。
3. 鉴定方法。写选用的主标准和方法前提。前提不成立时，本段直接写不能按该方法鉴定。没有用到的方法不要充数。
4. 分析说明。先解决事故形态、数据相关性或目标对应，再推导速度、接触关系、行为或灯色。每条关键判断末尾【出处：《标准名》条款号】。事实与假设分开写。材料不够时写明不能判断的范围。
5. 咨询意见。一段话，一个结论，写全对象、部位或方向、时点或时段、位置、数值单位和支持程度。允许的句式是确定结论，或「现有检材不符合《标准名》的鉴定条件，不能作出咨询意见」。禁止「大约」「可能全责」「建议认定主责」。
6. 限制。写明本文不是司法鉴定意见书，不替代交通事故责任认定；重庆地方标准只有在其适用范围内才引用。附件只列本案实际使用的材料。

补充身份或委托单位时，未改动的段落保留，不要改结论。不得伪造机构、资质、签章或已经签发。用户要求 Word 或 PDF 时，另用可用的文档技能，并核对渲染。

## 与专项的关系
