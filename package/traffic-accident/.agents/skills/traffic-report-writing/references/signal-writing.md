# 信号灯状态报告

例源：S01（2022固定配时、多段过街及实测差异）、S10（2024自适应、目标不可见、多视频与时序图）。它们展示推导路径，不提供其他路口的默认周期或互锁规则。

## 检验内容与目标定义

以现场图和照片确定道路方向、停止线/过街分段、安全岛、灯组位置编号、控制方向和车道/交通流，不把灯杆位置等同受控方向。写清所求为前轮/前缘/其他明确部位过哪条线、何时或何段，不以事故碰撞时刻替代进入路口时刻。

检配时版本及对应日期时段、星期、运行模式、相位顺序、黄灯/全红/绿闪与行人二次过街关系；纸面配时不自动等于事发实际执行。逐灯区分直接可观测目标、参考灯和不可观测灯，不凭他向车辆通行推本向灯色。

## 时间与推导

登记原始视频及时间依据，逐帧记录确可辨认的亮灭/颜色转换、全局号和叠字；遮挡、色偏、曝光/闪烁、局部亮度不足须说明，暗灯不自动为熄灭或红灯。多视频利用共同目标/事件作同步，记录偏移和误差，不能仅凭叠字相同假定同步。

目标不可直接看见时，说明参考灯与目标的控制关系及证据，先验证实测周期/相位与配时是否相符，再定位过线区间。S01用观测差异及敏感性分析判断差异是否影响结论；不能仅见某相位差1秒就无证据改全路口配时。S10按自适应周期和相位比例推导边界，不能拿前一周期固定时长外推下一周期。

把全部误差纳入过线和灯色转换区间。若目标过线区间跨越转换边界，明确可能状态，列缩小不确定性所需材料；不能强行选单一颜色。只有充分证明误差不会改变灯色归属，才写“上述差异不影响结果”。

## 图与意见

时序图统一零点、秒/帧刻度、灯组对应方向、色段、边界区间、目标过线范围及图例；用文字标色，不以光滑图形假造精确秒数。自适应可用上下界/包络，不能画成已观测的单值。

意见框架：“【对象及部位】于【方向、具体停止线/过街段】通过【位置/时段】时，对应【灯组及控制方向】的指示状态为【颜色或可能范围】【支持程度】。”S01分北/南段出不同灯色，说明同一次事故也需分问题回答。灯色技术意见不自动写“闯红灯”“负全责”，车辆法律类型/信号适用争议交对应依据确认。
