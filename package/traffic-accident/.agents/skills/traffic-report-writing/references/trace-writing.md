# 痕迹与接触碰撞报告

例源：S08（2023）、S11（2024）、S04（2025）。S08示造痕客体特征推断及否定，S11示成对比对及差异解释，S04示候选造痕体逐一排查；三者的结论不能作为新案件预设。

## 检验描述

对象编号、唯一标识、方向/部位→痕迹种类→形态和尺寸/距地高度→排列/间距/细节→加减层及附着物→变形/作用方向证据→相邻结构、图号及观察条件。没有尺寸记录不能从示意图补数；没有专门检验时写“样”“类”“附着物外观”，不直接定物质成分来源。

覆盖与委托有关的其他部位，写清未检见的范围、新旧判断依据及照片/实物观察限制。参考答案“应描述某处未见异常”仅针对其试题检材，不能把新案未拍摄部位写成无痕。

## 分析递进

1. 根据承痕特征推候选造痕部件的形态、材质、凸出、纹形、尺度及运动特点，标“种属/候选”而非立即锁定车辆。
2. 对候选痕迹对编号，分别比部位/高度、形态/细节、物质转移方向、受力、形成机制；轮胎花纹须看范围、纹形、节距、排列，不凭颜色/同高认定。
3. 将多对痕迹放入整体空间和运动关系中，区分直接车车接触、人体衬垫接触、倒地、二次接触、旧损和维修。
4. 对每个差异说明是否本质及证据。S11的制动点头解释只对其条件成立；新案高度不同不能一概归为点头，须核车辆载荷、制动、姿态、测量、结构变形等是否足以解释。
5. 处理关键矛盾、其他候选部件及应检未检项，得出与证据强度相称的意见。未知区域不能作为已排除来源。

## 结论力度

“不能认定发生碰撞”表示证据不足以认定；“可以排除发生碰撞”需要足够且有效的否定依据；二者不能因为S04答案以斜线并列就当同义词。未检见痕迹≠从未接触。排除特定痕迹由某部件形成，也不自动排除车辆间其他接触。

意见明确对象、部位和接触方式，例如“【甲车】的【部位】与【乙车】的【部位】发生过接触碰撞【与证据相称的用语】”。只能推造痕体类别时不越级作车辆同一性结论；不可判定说明缺哪一类证据。碰撞事实不自动证明事故责任。
