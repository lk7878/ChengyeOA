# 写作复核与修改交付

## 完稿前检查

- 每项委托有对应答案；对象VIN/别名、人名、灯号、左右/方位、碰撞次序一致；确定性没有在润色后升高。
- 已有证据与待提供材料分开；案情来源、材料确认及检验实施主体清楚；未检验/照片未覆盖不能写“未见异常”。
- 方法适用已说明；案例旧标准、机构编号、软件版本、哈希和数值未自动移入本案；能力验证答题表和字数要求未当法定格式。
- 事实、测量、记录字段、假设、计算和判断逐层可追溯；关键结论不是一句“综合分析”带过。
- 均速/瞬时、触发/碰撞、报警/事故、GMT/当地时间、录制/叠字/播放时间、全局帧/秒内帧没有混淆。
- 图、表、参数和正文一致；公式按原页核数学上下标和根号；重新复算单位、加减、括号、时间跨秒及小数精度；不直接信PDF线性提取的公式。
- 所有重大替代解释与差异已处理；“未见”“不支持”“不能认定”“可以排除”“可以成立”用语有各自依据；不存在仅凭阴性所见作排除。
- 速度上下界舍入不会缩小无依据区间；严格不等号和约值有根据。样例仅为答案，不是统计置信区间来源。
- 附件/截图确存在、编号可找、来自本案，处理有记录；时序图/痕迹对应图没有超出证据精度。
- 草稿、待核验字段、未实施项目已明示；签章资质信息未伪造；实质改变已签发意见已转机构程序处理；未越到法律责任认定。

## 自查/改写的交付方式

按问题逐项给出：原文位置和原意→问题类型→证据/方法依据→对意见的影响→建议改写或补查。必要时区分表达缺陷、材料缺口、技术方法疑问、程序待核；不能只因未在当前摘录见到就确认原机构没有做过。

简单改写直接给修订稿，说明任何可能影响原意的改动。复杂审查先解决会改变结论的身份、时点、数值、因果和证据问题，再修格式。保持可核的原稿，不以删除矛盾段落代替解决矛盾。

当现有材料不能支撑全文时，交付有依据章节和单列缺口，例如缺原视频无法核帧率/选点、缺EDR限制说明不能判采样速度有效、缺尺度/体位不能补损伤高度。明确缺什么、影响什么、取得后如何复核，不将这些缺口藏在统一免责声明中。
