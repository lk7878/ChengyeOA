# 报告结构和证据组织

## 按交付用途选择结构

完整报告底稿通常包括基本情况（委托人、受理/鉴定日期、地点、事项、材料等）、基本案情、鉴定过程（方法、检验所见）、分析说明、鉴定意见、附件及待机构签发字段。范例的能力验证编号、统一页脚“实施日期2018-1-2”不是本案受理日期；部分答案只给要点或计算表，不能据此认为其他章节可以省略。

计算类答题可按非视频信息→视频与关键帧→参数依据→公式计算→分析说明→鉴定意见编排；正式报告将计算表、截图放相应章节或附件。用户要求特定格式时适配结构，保留证据链。2024车速答案的“300字以内”仅约束该题分析说明，不作为所有报告限制。

## 接收材料后先做三份工作底稿

1. 对象与问题清单：车辆/人/道路设施别名、唯一标识及确认来源；每一问题的目标时点/路段/部位；多次碰撞分别编号，不混为“事故时”。
2. 证据清单：材料编号、名称、提供方及确认、原件/副本/截取件、数量/状态、日期、对应事实和局限。数字文件登记实际文件名、哈希、提取/接收记录；参考答案内记载的其他文件哈希不能当本案文件哈希，也不能当该答案PDF自己的哈希。
3. 论证清单：拟证明命题、支持记录、反证和替代解释、所用方法、参数来源、限制、可达意见层级。只有计划时不能写已检验结果。

这三份按任务简化，不强制全部出现在报告正文。缺少原始视频、EDR导出或实物时，不从参考答案反推它们存在；使用二手结果应注明来源与核验限度。

## 章节写法

基本案情说明来源，区分事故发生、报警、摄像机叠字和记录时间；仅摘取与事项有关的事实，不把警方初判或当事人陈述先写成鉴定结论。

鉴定方法写实际采用的方法、适用标准版本/条款和条件，不把案例引用清单照搬。没有用到的方法不要充数，未提供全文的方法不虚构条款。技术依据查新与案例年份分别处理。

检验所见按材料或对象分项，先唯一标识和总体状态，再关键特征。将客观所见与推断分开，例如“附着黑色类橡胶物质”不等于已检验确认为某车橡胶；“踏板字段为On”不等于已证实主动避险。重要阴性发现写清检验覆盖范围、可观察条件，不能凭材料缺失填“未见异常”。

分析说明以命题递进：依据哪些记录→如何建立对应/参数→方法为何可用→结果→差异和误差→能支持到何种程度。每个关键结论有具体记录或图号支撑，不连续堆“综合分析”替代理由。不以证据数量简单投票。

鉴定意见只回答委托事项，用“对象＋时点/位置/部位＋技术结论＋适当限制”表达。用语依适用专业规范和本案证据选；“可以成立”不是统一保守后缀，更不是置信概率。无法判断时说明现有材料不能确定的具体事项，并列可补查证据。

## 图、表和可复算性

截图标注源文件、帧号（说明全局号/秒内号）、时间基准、特征点和参照线。保留原帧，增强/裁切/标注记录处理，不能用生成图像填补证据。

每张图单独成段，图题写在图片标记里，不要嵌进上下句，也不要放进表格。这样导出 Word 时图片按版心居中嵌入，图题留在图下，不会因为正文首行缩进或固定行距被裁切、挤到段尾。

参数表建议每项包含符号、含义、原数值单位、统一单位、来源编号/页/图、取值理由、误差/适用条件。公式逐步代入，单位换算单列，末步再舍入；区间上下界和严格/非严格不等号保持一致。

痕迹对照图标清对象、方向、尺度、痕迹编号和对应关系；不同角度/姿态的照片不伪造等比例叠合。信号灯时序图标明时间零点、灯组和方向、颜色含义、过线时间区间与边界不确定性，颜色之外加文字。图示推断和直接观测分开标。

附件只列实际存在并使用的材料。照片、视频、EDR原导出、分析派生、计算记录及签发底稿保留关联；不能仅复制参考答案的附件清单冒充交付。
