# 交通行为方式报告

例源：S07（2023报告纠错）、S03（2025完整示范）。S07不是骑行结论范文模板，而是提醒缺受理/地点、案情来源不清、关键车痕与损伤描述不足、未检现场图、未建对应和未处理替代假设等质量问题。

## 分析顺序

先明确委托为驾乘、骑推或其他体位/行为问题及关键时刻，再写车辆结构痕迹、人体损伤、衣物/物质等检验，建立事故接触形态；随后分析特征损伤与致伤结构的对应和形成机制，最后比较候选行为。

人体损伤按适用检验规范和实际记录描述位置、形态、走行、尺度、间距、距足底高度，注明治疗、姿态或保存状态影响。未做尸表/临床检查时，明确取自照片或报告；本技能不授权实施人体检验。

典型证据优先不等于单痕决定：将对应部件结构、痕迹/损伤的形态和位置、物质转移、人体与车辆空间阻隔、行进方向、倒地后损伤及视频相互验证。有转移附着物而缺检验，标明可能支持/区分作用及不能确定的来源。

按候选分别写“若骑行/推行/左右侧位置，则在本案结构和运动条件下预期何种接触；哪些已见、矛盾或未知；替代形成方式能否解释”。不将推车习惯、鞍座物品、单处DNA、未破风挡或未见某损伤单独作为身份/行为结论。

S03展示“事故形态→人车损伤对应→推行与骑行比较”的层级。其左右侧称谓存在需核之处（见来源索引），不得借例中结论自动校正新案的人车位置，也不得把未见高部位接触推广为骑行必有高部位碰撞。

## 意见表达

“【车辆与人员】发生【具体接触/时点】时，【人员】的交通行为方式为【明确行为或不能判断的事项】【适当支持程度】。”如骑行、推行和一侧推行只能证实其中一层，只写到该层；案发前后行为不能替代碰撞时行为。不得由行为鉴定直接写法律违法或责任比例。需要伤情/死亡原因等另用相应专业方法。
