# EDR车速报告

例源：S02（2022）、S12（2024）、S05（2025）。可借鉴的主线为事故形态→事件相关性→完整性→各字段有效性→车速/操作分析→对应意见，不能直接套事件编号和车速。

## 检验所见与事件对应

描述车辆VIN、模块外壳/硬软件信息、轮胎及约束系统状态，注明取自实物、照片还是说明文件。EDR材料登记实际文件名/哈希、工具及版本、提取时间/人员、提取方式、控制器、事件数量及原编号、锁定和完整标志、上电周期、日期时区、采样率、相对时间零点、关键字段与不可用值。PDF报告不自动等于原始读取记录。

以独立材料重建接触顺序，再分别说明每个事件为何对应哪次接触：车辆/模块身份，事件时间及间隔与视频比对，上电周期、受力方向/坐标约定、气囊和预紧器触发、损伤部位等。事件编号不必按事故先后排列，上电周期相差1不能单独证明相关；读取/保存时间不同于事件时间。时区换算和跨日要留计算。

合并事件时选明统一时间基准，保留各自零点；检验重叠样本能否对应。每事件/每字段分别下判断，“记录完整”不自动证明车速有效，更不能证明所有事件在碰撞后仍有效。

## 有效性和车速

核数据限制说明、速度来源、轮胎滚动半径/规格、传动比、胎压、抱死/空转/侧滑/车轮离地、车辆改装和多次碰撞造成变化。说明是否仅影响某事件某时段，而非整份文件一刀切。胎压未报警、ABS未激活不单独证明不存在打滑/失压。

delta-V是速度变化量，不是行驶速度；其方向需用该模块坐标/符号说明，不能套另一车型。触发零点不当然为首次接触时刻，字段采样间隔、量化、延迟和触发定义必须核实。最后一采样值不能无论证直接改称瞬时碰撞速度。

按有意义时段叙述速度、制动、加速、转向、巡航/辅助系统变化，解释字段能证明什么。制动/转向字段改变不能单独认定驾驶员主动避险或误操作；区分驾驶输入、自动系统、碰撞受力和未知。S12展示不能判断主动措施，S05展示不同接触阶段需分开分析，均非通用因果结论。

## 意见写法

先给采样层事实，例如“事件【编号】相对触发时刻【-0.5s】的车速字段记载为【数值】”；通过本案关联和有效性分析后，才能写“【车辆】于【具体碰撞/时段】的速度约【值/区间】”。若只能确认记录速度，意见中保留“记录”与时点，不把无法验证的真实车速写确定值。

多次碰撞按对象及次序分别答复，解释采用哪个事件、为何不采用其他事件。间隔、未记录和空值保持原义，空白不等于0、未触发不等于装置不存在。参考答案中的安全带推断、上电周期解释和瞬时速度判断须重新基于本案模块说明与证据核对，不能仅复制措辞。
