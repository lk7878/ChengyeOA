# 力学与视频车速报告

例源：S09（2023）、S13（2024）、S06（2025）；页码见来源索引。它们展示不同材料条件下的方法取舍，不形成“视频必优于力学”或相反的普遍规则。

## 从所求速度反推报告内容

先定义所求为采取措施前、制动痕迹起点、首次接触、后续碰撞、区间平均还是采样速度。整理可见时段、制动灯/减速开始证据、痕迹起终点和碰撞时点，写清坐标、参照、时间依据及误差。末段意见必须回到同一个速度定义。

S09、S13借视频中的车体特征与尺寸计算路段速度，再定位痕迹产生区间、结合制动协调时间论证所测时段是否在制动前。S06视频不足以直接覆盖制动前且几何条件较差，改用现场制动痕迹和可比测试数据。方法选择要说明本案的可观测性、量测条件和参数质量，不能为复现案例数值优先挑某种方法。

## 视频检验写法

登记源文件、载体、实际哈希、时长、分辨率、编码/帧率和使用工具；连续性、丢/重帧及时间可靠性有记录才下判断。区分名义帧率、实际PTS、画面叠字和播放器时间；确认时间模式后才用帧差除以帧率。秒内第25帧与下一秒第1帧要按约定计数，不能自动多计端点。

每个关键帧说明车辆部位、参照物、重合/介于关系、物理距离依据和对应运动方向。车身长度/轴距当尺度须核视角、投影、深度和姿态，不能任意用图像距离等比例套实距。

若距离只能夹在两个界限，保留其界限而非取中点伪精确。给出距离、时间的取值条件及不确定性，再给速度界限。简化 v=s/Δt 只给该时段平均速度；推制动前或瞬时速度须另有稳态/短时、加速度、事件对应论证。

## 力学检验写法

报告质量、痕迹性质/长度/对应车轮、路面、坡度、终止速度、测试装载/路面/车辆状态等。检验时MFDD不能不经可比性论证当事故减速度。若取等效匀减速模型，说明减速度来源和适用区间；协调时间内减速度演变另有模型，不能通用地都加0.5at。

S09、S06用能量关系及协调阶段近似进行示范，报告应写适用假设及忽略项影响：碰撞耗能、被撞对象运动、其他耗散能否忽略须按本案证据和敏感性分析支持，不能仅因为大车比小车/行人重就恒设碰撞能量为零。摩擦系数、减速度、协调时间不得填案例默认值。

## 综合分析与意见模板

说明两种方法测的是否同一时点、参数是否独立、结果差异能否解释。结果一致支持相容性，不能消除共同误差；不同方法不直接平均。无法覆盖所求时点就降低结论范围，不强行拟合答案。

可用表达框架（须填本案实证值）：

“依据【材料及记录编号】，在【帧/时间区间】内，【特征点】相对【参照】移动的实距为【区间、单位】，历时【时间及依据】，所得为该区间平均速度【结果】。结合【制动时点、运动状态证据】，该结果【能/不能及原因】用于表述【目标时点】速度。”

鉴定意见例如“【车辆标识】在【明确路段/采取措施前/某次碰撞时】的【速度类型】为【约值/界限及单位】”。明确“约”还是上下限，别将区间中点写作确定值。来源S13的算术、S06的时间文字有已核疑点，见来源索引；本案必须重新计算。
