# 涉案者交通行为方式鉴定

本技能不读取 `references/`。意见类型和认定条件只来自 `weknora_search` 命中的 SF/T 0162—2023《道路交通事故涉案者交通行为方式鉴定规范》。未命中写「条款未能核实」。

## 检索

下结论前调用 `weknora_search`。query 写「道路交通事故涉案者交通行为方式鉴定规范」加状态或「意见」。同一轮最多 4 次。

- 「道路交通事故涉案者交通行为方式鉴定规范 驾驶」
- 「道路交通事故涉案者交通行为方式鉴定规范 乘坐」或「骑行」「推行」「行人」
- 「道路交通事故涉案者交通行为方式鉴定规范 意见」

只保留标题含 SF/T 0162 或该书全称的命中。认定、否定、倾向、无法判断的条件和措辞以命中原文为准，不把「可能形成」写成「必然就是」。引用写成【出处：《道路交通事故涉案者交通行为方式鉴定规范》条款号】。

## 审查

1. 先定要判断的是某一时刻的汽车或摩托车驾乘、自行车等的骑行或推行，还是行人的体位。列出候选状态。事故过程和能否检验，先写清楚。
2. 对应车辆部位、座椅和约束，人体、衣着和鞋，物质交换，痕迹方向、高度和轨迹，逐项检验。微量物证、DNA 或法医意见由相应专业完成，本技能只审查其来源和限制。
3. 方向盘上的 DNA 或指纹、座位上的物品、平时使用痕迹，可以说明接触过，不能单独证明事发时在驾驶。救援、移动、换位、抛出和治疗改变要逐项排除。不能凭一处所谓典型驾驶损伤定人。
4. 骑行、推行和体位要同时看损伤、接触高度、车辆结构、新近痕迹和成伤阶段。静态身高或痕迹高度，不能无条件代替碰撞时的姿态。
5. 每个候选状态都列出支持和不支持的证据，以及另一种可能的过程。

## 输出

结论只写事发时的行为状态。是否饮酒、如何操作、是否违法、责任比例，需要独立证据，不从本鉴定直接推出。
