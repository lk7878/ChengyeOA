# 基于图像的现场与过程重建

本技能不读取 `references/`。时间、控制点、共线和共面条件只来自 `weknora_search` 命中的 SF/T 0160—2023《基于图像的道路交通事故重建技术规范》。未命中写「条款未能核实」。要给速度数值时改加载 `video-speed-appraisal`。计算机动力学再现改加载 `accident-simulation-reconstruction`，并说明它与本重建是否独立。

## 检索

下结论前调用 `weknora_search`。query 写「基于图像的道路交通事故重建技术规范」加事项。同一轮最多 4 次。

- 「基于图像的道路交通事故重建技术规范 视频」或「时间」
- 「基于图像的道路交通事故重建技术规范 控制点」或「摄影测量」
- 「基于图像的道路交通事故重建技术规范 车载」
- 「基于图像的道路交通事故重建技术规范 点云」

只保留标题含 SF/T 0160 或该书全称的命中。引用写成【出处：《基于图像的道路交通事故重建技术规范》条款号】。

## 重建

1. 先定重建的是静态位置和尺寸，还是动态轨迹。选择固定视频、车载视频、照片或点云。核对原始图像、处理过程、畸变、相机是否移动、特征能否辨认。
2. 同时检查时间戳、叠加时间和帧率。重复帧、缺帧的处理要保留原始索引、依据和误差。不生成用来代替事实的新帧。
3. 按命中原文选择一维共线、二维共面或点云。控制点数量够不够，还要看几何分布是否覆盖目标。地面上的单应关系不能直接用到任意车顶部件。目标特征和标定不在同一高度时，按命中原文处理，不默认可以混用。
4. 在统一现场坐标里测量。仪器和至少一段实尺要能核对。保留没有参加拟合的检查点、重投影或物方残差，以及不能外推的范围。
5. 车载图像的映射随帧更新。虚拟接地点的条件不成立时，不用它直接代表本车位置。图像里的其他车、镜头所在的本车、相对运动，分开写。
6. 照片里散落物的位置，不能自动推出落地前的轨迹。特征点的区间平均速度，不是完整的运动过程。

点或时间、尺度不够时，只写条件分析和要补的材料。

## 输出

附原始图和标注图、控制点、坐标变换、时间轴、轨迹节点、平均速度的定义、残差和不能重建的区间。
