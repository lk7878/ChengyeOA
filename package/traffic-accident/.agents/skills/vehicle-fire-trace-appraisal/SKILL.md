# 车辆火灾痕迹与物证

本技能不读取 `references/`。起火部位、起火点和原因的检验要求只来自 `weknora_search` 命中的 SF/T 0100—2021《车辆火灾痕迹物证鉴定技术规范》。未命中写「条款未能核实」。没有痕迹和燃烧残留的描述时，不确定起火原因。

## 检索

下结论前调用 `weknora_search`。query 写「车辆火灾痕迹物证鉴定技术规范」加事项。同一轮最多 4 次。

- 「车辆火灾痕迹物证鉴定技术规范 起火部位」
- 「车辆火灾痕迹物证鉴定技术规范 电气」或「油液」「机械」
- 「车辆火灾痕迹物证鉴定技术规范 提取」或「取样」

只保留标题含 SF/T 0100 或该书全称的命中。引用写成【出处：《车辆火灾痕迹物证鉴定技术规范》条款号】。有损检验是否要书面同意，同时核对 SF/T 0072 的命中原文。

## 审查

先固定车辆身份，起火前后的视频、车载或新能源平台数据，停驶或碰撞的顺序，灭火、救援和破拆、移动。实物按少扰动的初检、细项、专项推进。记录燃烧终止线，炭化、烟熏、熔化和残留，各方向高度，以及通风和可燃物的差异。

用蔓延方向和多个部位的痕迹把范围收到起火部位，再到点位。机械摩擦、电气、油液和外来因素分别检验。烧损最重，或单独一颗熔珠，不能直接当成起火原因。故障引发的火和火后短路、碰撞造成的泄漏或电气损坏和火前损坏，分成不同的时间链。

取样前先记录，并评估断电、高压和电池残留风险。按命中原文清洁、分装，保留对照、熔痕和整体结构。不为了寻找起火点而没有记录地清洗、拆解，或用热切割破坏痕迹。没有资质和条件时只写方案。

成分、油液、熔痕或电池的专项结果，要和现场条件交叉验证。检出助燃剂不能直接证明放火，更不能证明行为人。

## 输出

分开写起火区域或点位的确定程度、蔓延、可能原因和排除依据、材料损失、不能判断的部分。事故先后和责任另论。
