# 文书草稿与来源对照

1. 确认文书类型、受文机关、当事人立场、目标和格式要求。
2. 先编列已核验事实、必要要件、请求事项和缺失信息。
3. 身份、金额、日期、证据编号以材料为准，不以示例补齐。
4. 请求、事实理由、法律依据、证据目录分别成段并相互一致。
5. 未核验法源明确占位；不得伪造案号、条文或裁判引文。
6. 计算金额、利息和期间时写明公式与起止假设。
7. 保存 Markdown 草稿，需要时用原有 Word 工具导出，并列出待律师确认项。
