# 证据整理

建立证据目录，按请求权要件归组，记录名称、来源、固定版本、页码、证明目的、真实性/合法性/关联性疑点及补证建议。区分原件、复制件、OCR与单方陈述；冲突材料不可遗漏。

开展任务前读取同目录 `CHECKLIST.md`，按其步骤及表格结构交付。

## 输入与工具协议

1. 先读工作目录中的 task.json，按其中固定版本材料开展工作，只读取 materials/。不得扫描其他案件、用户目录或服务器文件。
2. 原件不可覆盖；解析中间件写 drafts/，供律师审核的输出写 reports/。
3. 使用已配置的知识检索工具核验来源。没有检索工具或调用失败时明确报告，不能声称检索完成，不以模型记忆替代最新法源。WeKnora 仅允许本任务获授权且已发布知识。
4. 来源表使用 fileId、version、页码/条款/行号、原文、核验状态。页码无法确定时写明原因，不伪造页码。
5. 本 Skill 不授予访问、分享、投稿或归档权限。OA 负责身份、案件和文件，工作台负责审批与保存。不要调用飞书、北大法宝 MCP、外部事项台账或其他平台管理目录。
6. 可以串联证据整理→事实时间线→分析→起草→文书复核。成稿仍须律师复核，失败与材料缺口必须披露。
