# 合同审查清单

1. 确认审查立场、合同版本、交易结构及已知谈判约束。
2. 先查主体、标的、对价、履行、验收、违约、解除、通知、争议解决。
3. 检查定义、交叉引用、附件优先级、时间金额与各条款之间的矛盾。
4. 识别单方变更、默认验收、责任限制、连带责任与权利放弃。
5. 风险以触发条件、后果、证据和可实施的替代条款解释。
6. 区分必要修改与可谈判商业条件，不擅自替当事人接受风险。
7. 同时给出问题清单、建议文本、待确认事实，保留原版本。
