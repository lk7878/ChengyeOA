# 文书复核问题表

1. 适用于 AI 草稿和律师上传的文书；先记录被审文书版本和审查范围。
2. 逐项核对姓名主体、日期金额、请求与证据目录。
3. 核查每项事实是否有材料支持，以及是否把单方陈述写成定论。
4. 检验法条、案例、引文和链接，无法核验必须列为问题。
5. 检查逻辑矛盾、缺失前提、附件编号、条款引用及计算结果。
6. 问题必须定位到页码、标题、段落或引用原文，并给出修改建议。
7. 报告保留问题与核验限制，不能把未发现问题当作法律质量保证。
