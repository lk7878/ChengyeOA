## 1. 产品概述

### 1.1 产品定位

律所管理系统是一款面向中小型律师事务所的**一体化业务管理平台**，覆盖从**线索获取 → 客户转化 → 合同签署 → 案件办理 → 收款结算 → 绩效评估**的完整业务闭环。

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| **业务闭环** | 线索到收款全流程数字化，消除信息孤岛 |
| **效率提升** | 自动化审批、智能提醒、一键转客户 |
| **数据驱动** | 实时仪表盘、转化漏斗、财务分析 |
| **合规安全** | 操作日志、权限控制、数据加密 |

### 1.3 产品愿景

> 打造律师行业最易用、最全面的数字化管理工具，让律所管理者专注业务，让数据创造价值。

## 2. 目标用户与角色

### 2.1 用户角色定义

| 角色 | 职责 | 核心诉求 |
|------|------|----------|
| **合伙人/主任** | 律所最高管理者 | 全局数据、财务监控、团队绩效 |
| **部门主管** | 部门负责人 | 部门业绩、人员管理、案件分配 |
| **律师** | 案件承办人 | 案件管理、客户沟通、任务跟踪 |
| **销售/运营** | 线索跟进、客户转化 | 线索管理、跟进记录、转化统计 |
| **行政/HR** | 人事管理、审批处理 | 员工管理、考勤、审批流 |
| **财务** | 收款管理、合同台账 | 收款确认、退款、财务报表 |

```

行政/HR ─────► 员工管理 + 审批管理

```

## 4. 详细功能需求

### 4.1 认证中心 (Auth)

#### 4.1.1 用户登录
- **场景**: 用户输入用户名密码登录系统
- **输入**: 用户名、密码
- **处理**: 校验密码 → 生成 JWT Token → 记录登录日志
- **输出**: Access Token + Refresh Token + 用户信息 + 权限列表
- **异常**: 用户名密码错误 / 账号禁用

#### 4.1.2 Token 刷新
- **场景**: Access Token 过期后自动刷新
- **输入**: Refresh Token
- **处理**: 验证 Refresh Token → 生成新的 Access Token
- **输出**: 新的 Access Token

#### 4.1.3 获取用户信息
- **场景**: 页面加载时获取当前登录用户信息
- **输出**: 用户基本信息 + 员工信息 + 角色 + 权限

#### 4.1.4 用户登出
- **场景**: 用户主动退出系统
- **处理**: 客户端清除 Token（服务端可选黑名单）

---

### 4.2 用户管理 (User)

#### 4.2.1 用户列表
- **功能**: 分页展示系统用户，支持按用户名/员工姓名搜索、按状态筛选
- **字段**: 用户名、关联员工、角色、状态、最后登录时间

#### 4.2.2 创建用户
- **前置条件**: 需先创建员工（可选关联）
- **字段**: 用户名（唯一）、密码、状态、关联员工
- **校验**: 用户名唯一性校验

#### 4.2.3 角色分配
- **功能**: 为用户分配一个或多个角色
- **影响**: 角色变更实时影响用户权限

#### 4.2.4 禁用/启用用户
- **场景**: 员工离职时禁用账号
- **处理**: 状态设为 DISABLED，禁止登录

---

### 4.3 角色权限 (Role & Permission)

#### 4.3.1 角色管理
- **角色类型**:
  - `SYSTEM`: 系统预设角色（不可删除）
  - `BUSINESS`: 业务自定义角色
- **默认角色**: 超级管理员、合伙人、部门主管、律师、销售、财务、行政

#### 4.3.2 权限体系
- **权限类型**:
  - `MENU`: 菜单权限（页面访问）
  - `BUTTON`: 按钮权限（操作控制）
  - `API`: 接口权限（数据控制）
- **权限编码规范**: `模块:操作`，如 `user:create`, `lead:assign`

#### 4.3.3 权限树
- **功能**: 树形展示所有权限，支持按角色勾选分配

---

### 4.4 组织架构 (Organization)

#### 4.4.1 组织类型
- `FIRM`: 律所总部（根节点）
- `BRANCH`: 分所
- `DEPARTMENT`: 部门（刑事部、民事部、商事部等）

#### 4.4.2 组织树
- **功能**: 树形展示组织架构，支持拖拽调整
- **约束**: 删除组织前需先清空下属岗位和员工

---

### 4.5 员工管理 (Employee)

#### 4.5.1 员工生命周期

```
入职录入 ──► 试用期 ──► 转正 ──► 正式员工 ──► 离职
                │                      │
                ▼                      ▼
           创建系统账号            禁用系统账号
```

#### 4.5.2 员工类型
- **合伙人**: 律所合伙人，最高权限
- **资深律师**: 独立承办案件
- **初级律师**: 协助办案
- **律师助理**: 文书、调研
- **销售**: 线索跟进、客户转化
- **行政/HR/财务/运营**: 职能岗位

#### 4.5.3 关联约束
- 员工离职 → 自动禁用关联用户账号
- 员工删除 → 需先解除所有业务关联（线索、案件等）

### 4.6 渠道管理 (Channel)

#### 4.6.1 渠道类型
- 线上: 搜索引擎、短视频、直播、信息流、微信
- 线下: 转介绍、自然流量、线下活动

#### 4.6.2 渠道统计
- 线索数量、转化率、投入产出比
- 支持按时间段筛选

---

### 4.7 线索管理 (Lead) — 核心业务流

#### 4.7.1 线索生命周期

```
新线索 ──► 已联系 ──► 已筛选 ──► 已邀约 ──► 已到访 ──► 洽谈中 ──► 已报价 ──► 已签约 ──► 已流失
   │         │          │          │          │           │          │          │
   │         │          │          │          │           │          │          │
   ▼         ▼          ▼          ▼          ▼           ▼          ▼          ▼
 录入      跟进       评估       邀约       面谈        报价       签约      归档
```

#### 4.7.2 线索录入
- **来源**: 手动录入、渠道自动导入、API接入
- **必填**: 姓名、电话
- **选填**: 微信、渠道、来源详情、意向等级、标签

#### 4.7.3 线索分配
- **自动分配**: 按轮询/负载均衡分配给销售
- **手动分配**: 主管指定负责人
- **回收机制**: 超过 N 天未跟进自动回收至公海

#### 4.7.4 跟进记录
- **跟进方式**: 电话、微信、到访、线上、其他
- **记录内容**: 沟通内容、下次计划、下次时间
- **状态联动**: 首次跟进自动将线索状态改为"已联系"

#### 4.7.5 转客户
- **触发条件**: 线索签约或达成服务意向
- **处理**: 自动创建客户档案，保留线索关联
- **约束**: 已转客户的线索不可删除

#### 4.7.6 线索回收
- **场景**: 负责人离职或长期未跟进
- **处理**: 清除负责人，状态重置为"新线索"

---

### 4.8 客户管理 (Customer)

#### 4.8.1 客户来源
- 线索转化（自动关联）
- 直接录入

#### 4.8.2 客户状态
- `POTENTIAL`: 潜在客户（刚转化）
- `INTENT`: 意向客户（已沟通需求）
- `SIGNED`: 已签约（有生效合同）
- `INACTIVE`: 流失（长期无合作）

#### 4.8.3 客户画像
- **基础信息**: 姓名、电话、微信、身份证、邮箱、地址
- **标签体系**: 支持多标签，如"高净值"、"企业客户"、"常法"
- **关联数据**: 合同列表、案件列表、收款记录

---

### 4.9 合同管理 (Contract)

#### 4.9.1 合同生命周期

```
草稿 ──► 待审批 ──► 已审批 ──► 已签署 ──► 执行中 ──► 已完成
  │        │          │          │          │          │
  │        │          │          │          │          │
  ▼        ▼          ▼          ▼          ▼          ▼
创建     提交审批    审批通过    双方签署    服务提供    服务完成
                              │                      │
                              ▼                      ▼
                         已终止（异常）          已取消（异常）
```

#### 4.9.2 合同类型
- `CONSULTING`: 单次咨询
- `RETAINER`: 常年法律顾问
- `LITIGATION`: 诉讼代理
- `ARBITRATION`: 仲裁代理
- `MEDIATION`: 调解

#### 4.9.3 付款条款
- 支持多期付款定义（JSON格式）
- 示例: 签约30% + 立案30% + 结案40%

#### 4.9.4 审批流程
- 提交 → 主管审批 → 合伙人审批（大额）→ 通过/驳回

#### 4.9.5 合同台账
- 汇总视图：合同金额、已收款、待收款、执行状态

### 4.10 收款管理 (Payment)

#### 4.10.1 收款流程

```
创建应收 ──► 待收款 ──► 确认收款 ──► 已收款
                │                       │
                ▼                       ▼
             逾期（超期未收）          退款
```

#### 4.10.2 收款确认
- **字段**: 实收金额、收款日期、收款方式、收款账户
- **联动**: 更新合同已付款金额

#### 4.10.3 退款
- **条件**: 已收款状态才可退款
- **字段**: 退款金额、退款原因

### 4.11 案件管理 (Case)

#### 4.11.1 案件生命周期

```
待受理 ──► 已受理 ──► 办理中 ──► 已结案 ──► 已归档
   │          │          │          │
   │          │          │          │
   ▼          ▼          ▼          ▼
 接收材料    立案       开庭/执行   结果录入
```

#### 4.11.2 案件任务
- **节点类型**: 立案准备、材料收集、立案提交、开庭、文书提交、裁判反馈、执行、结案
- **状态**: 待办、进行中、已完成、已逾期
- **提醒**: 任务到期前自动通知

#### 4.11.3 沟通记录
- **类型**: 电话、会议、微信、邮件、其他
- **关键沟通**: 标记为关键，便于后续查阅

#### 4.11.4 结案
- **字段**: 案件结果、满意度评分、是否可转介绍
- **联动**: 更新客户状态、生成绩效数据

---

### 4.12 审批管理 (Approval)

#### 4.12.1 审批类型
- 退款审批、费用报销、合同变更、用印申请、请假、转所

#### 4.12.2 审批流程
- **简化版**: 申请人 → 主管审批 → 结果
- **复杂版**: 支持多级审批（后续迭代）

#### 4.13.5 案件指标

## 6. 数据流与业务流程

### 6.1 核心业务流：线索 → 收款

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  渠道   │───►│  线索   │───►│  客户   │───►│  合同   │───►│  收款   │
│ 投放    │    │ 跟进    │    │ 转化    │    │ 签署    │    │ 确认    │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
      │              │              │              │              │
      ▼              ▼              ▼              ▼              ▼
  渠道统计      跟进记录       客户画像       付款条款       收款计划
  投入分析      意向评估       标签体系       审批流程       逾期提醒
```

### 6.2 案件办理流

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  立案   │───►│  任务   │───►│  沟通   │───►│  结案   │───►│  绩效   │
```

### B. 状态机定义

**线索状态机:**
```
NEW → CONTACTED → SCREENED → INVITED → VISITED → NEGOTIATING → QUOTED → SIGNED
  │                                                                    │
  └────────────────────────────────────────────────────────────────────┘

```

```
DRAFT → PENDING → APPROVED → SIGNED → EXECUTING → COMPLETED
  │         │          │          │           │

  (任意状态可转为 TERMINATED/CANCELLED)
```
